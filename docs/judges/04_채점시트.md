# 합의 채점 프로토콜 + 3개 아이디어 채점 시트

작성: 2026-07-16 · 목적: 5인 심사위원 페르소나로 **우리 아이디어 3개를 객관적·냉정하게** 채점·비교하고, 제출 전 보완 우선순위를 뽑는다.

---

## A. 채점 프로토콜 (5인 → 하나의 판정)

### 1단계. 개요서 준비
- 아이디어별로 개요서 초안(또는 핵심 요약)을 텍스트로 준비. 빈 칸은 채우지 말 것 — **빈 칸이 곧 채점 대상**이다(심사위원은 "안 쓴 것 = 없는 것"으로 본다).

### 2단계. 5인 개별 채점 (독립)
- `03_심사위원_5인.md`의 **복붙용 시스템 프롬프트 5개**를 각각 새 세션에 넣고, 같은 개요서를 붙여 채점을 받는다.
- 반드시 **독립적으로** 돌린다(한 세션에서 5인을 순차 실행하면 앞 심사위원 의견에 오염된다). 냉정성을 위해 5개 별도 대화 권장.

### 3단계. 점수 집계 (예선 100점 환산 기준)
각 심사위원은 예선 배점(혁신성 60 / 시장성 20 / 기여도 20)으로 총점을 낸다. 아래처럼 모은다.

| 축(예선배점) | J1 도해심 | J2 배투자 | J3 문혁신 | J4 정공공 | J5 현산업 | **가중 반영** |
|---|---|---|---|---|---|---|
| 혁신성 /60 | | | | | | J3×2, J1×1.5 가중(주담당) |
| 시장성 /20 | | | | | | J2×2 가중 |
| 기여도 /20 | | | | | | J4×2, J1×1 가중 |
| **총점 /100** | | | | | | — |

> **가중 이유**: 예선 혁신성은 J3(혁신)·J1(기술)이 주담당이므로 두 사람의 혁신성 점수에 더 무게를 둔다. 시장성은 J2, 기여도는 J4가 주담당. 단순 평균보다 이 "담당 가중 평균"이 실제 심사에 가깝다.

### 4단계. 4개 핵심 지표 산출
1. **담당가중 평균 총점** (위 표의 가중 반영 열) — 아이디어의 기대 예선 점수.
2. **최저 심사위원 점수(worst-case)** — 가장 냉정한 1인의 총점. *예선 통과는 평균이 아니라 "가장 박한 심사위원도 통과권으로 보는가"에 가깝다.* 이 값을 중시.
3. **점수 편차(σ)** — 5인 총점의 표준편차. 크면(양극화) 리스크·설득 난도 높음. 작고 높으면 안정적 강자.
4. **미답 저격 질문 수** — 5인의 저격 질문 중 현재 개요서로 **답이 안 되는** 질문의 개수. 이게 곧 취약점 총량.

### 5단계. 판정 밴드 (예선 관점)
| 담당가중 평균 | 최저 심사위원 | 판정 |
|---|---|---|
| ≥ 80 | ≥ 70 | **강한 통과권** — 다듬어서 제출 |
| 70~79 | ≥ 60 | **통과 유력** — 미답 질문 절반 이상 해소하면 안정 |
| 60~69 | 55~64 | **경합권** — 최저점 심사위원의 축을 집중 보강해야 |
| < 60 | < 55 | **위험** — 축 하나가 구조적으로 비었을 가능성. 아이디어 재설계 검토 |

> 혁신성이 60점 만점의 축이라, **혁신성 단독이 낮으면 총점도 구조적으로 낮다.** 총점 미달일 때 먼저 J3 점수를 볼 것.

### 6단계. 보완 우선순위 도출
- 5인의 "+10점 보완 지시"를 모아 **중복 3회 이상 = 최우선**, 2회 = 우선, 1회 = 선택으로 정렬.
- 미답 저격 질문을 **발표 예상 Q&A 대본**으로 전환(본선·최종 대비).

## C. 청년 가점 & 부문 선택 체크

- **청년 가점**: 팀에 공고 마감일 기준 **만 39세 이하** 구성원이 있으면 예선 +1점(대표자 기준 확인). 총점 경합권일 때 이 1점이 당락을 가른다 — 신청서에 반영 가능한지 확인.
- **부문 선택(해양/수산/공통)**: 아이디어가 걸치면 **더 강한 코드로 명확히** 배치. 심사위원(J1·J4)은 "왜 이 분야인가"를 본다. 모호한 '공통'보다 또렷한 '해양' 또는 '수산'이 유리한 경우가 많다.
- **일반부 vs 학생부**: 팀원 전원이 대학원생 이하면 학생부 선택 가능(경쟁·기대치가 다름). `03`문서 부록의 가중 조정을 적용.
