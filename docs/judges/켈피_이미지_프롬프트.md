# 켈피(Kelpi) 아이템 이미지 — 생성 프롬프트 2종

> 팀원의 OpenTrap 이미지(엔지니어링 조립도 + 시스템 인포그래픽)와 **같은 비주얼 언어**로 통일하도록 설계함. 켈피는 하드웨어가 아니라 소프트웨어/AI이므로, 이미지1은 **제품 대시보드 목업**(신뢰), 이미지2는 **작동 흐름 인포그래픽**(이해)으로 잡았다.

---

## 🎨 공통 스타일 가이드 (두 이미지 통일)

- **팔레트:** 딥 네이비 `#0B3D4F` (주 라인·텍스트), 틸/시안 `#126E82`·`#1FA2B5` (해조·물), 오렌지 `#E8722C` (강조·처방·경고), 배경 화이트/아이보리 `#FBFBF9`
- **스타일:** 깔끔한 플랫 벡터 인포그래픽 + 반(半)사실적 일러스트, 얇은 라인·미세 그리드, 여백 넉넉, 정보밀도 높되 정돈된 편집디자인 (OpenTrap 도면 톤과 동일)
- **비율:** 가로형 16:9 또는 A3 가로 (개요서 삽입용)
- **언어:** 모든 라벨 한글 (아래 텍스트 목록 사용)
- **금지:** 과한 그림자·네온·3D 광택, 스톡사진 느낌, 어지러운 배경

> **텍스트 렌더링 팁:** 이미지 생성 AI는 한글을 자주 깨뜨린다. 두 가지 방법 권장 —
> (A) **GPT-4o 이미지 / Nano Banana(Gemini) / Ideogram** 등 텍스트에 강한 모델로 라벨까지 생성, 또는
> (B) 영어 프롬프트로 **텍스트 없는 일러스트만** 생성 → Canva/PowerPoint/Figma에서 아래 한글 라벨을 얹기(가장 안전, OpenTrap도 이 방식으로 보임).

## 🖼 이미지 1 — 켈피 진단 대시보드 목업 (요약 [이미지1])

**목적:** "이건 실제로 돌아가는 제품이다"라는 신뢰. 갯녹음 히트맵 + 원인 레이어 + 처방 카드 + 정착률/탄소 그래프를 한 화면에.

**생성 프롬프트 (영문, 복붙용):**
```
A clean, professional SaaS web dashboard UI mockup for a marine restoration analytics platform, flat vector infographic style, white/ivory background, palette deep navy #0B3D4F + teal #126E82 + orange #E8722C accent.
LEFT (60%): a top-down coastal seabed map of a Korean rocky shore. Healthy kelp-forest zones rendered in teal-green; barren "sea desertification" rock zones in pale pink/white. Semi-transparent color-coded "cause layer" polygons overlaid on barren zones — red = high water temperature, orange = sea-urchin grazing pressure, purple = crustose coralline algae cover, gray = substrate/nutrient. Small map legend.
RIGHT PANEL (40%): three stacked "prescription cards", each with an icon and short text — (1) urchin-removal-first, (2) heat-tolerant species, (3) substrate treatment. Below them a small bar chart comparing "treatment plot vs control plot" survival rate, and a line chart of cumulative CO2 absorption (tCO2). A KPI row at top with numbers.
Thin gridlines, generous whitespace, crisp modern editorial UI, no photographic texture, no drop shadows. High detail, poster-quality.
```

**얹을 한글 라벨:**
- 제목: **켈피(Kelpi) — 갯녹음 원인 진단 대시보드**
- 지도 범례(원인 레이어): `고수온` `성게 조식압` `석회조류 피복` `기질·영양염`
- 지도 상태: `건강한 바다숲` / `갯녹음(백화) 구역`
- 처방 카드: `① 성게 제거 선행` `② 내열성 종 이식` `③ 기질 처리 후 이식`
- 그래프: `정착률 — 처방군 vs 대조군` / `누적 탄소흡수량(tCO₂)`
- 상단 KPI: `진단 구역` `지배 원인` `예상 정착률` `예상 흡수량`

## 🖼 이미지 2 — 진단→처방→검증→크레딧 파이프라인 (요약 [이미지2])

**목적:** "이렇게 작동한다"는 흐름. OpenTrap 이미지2(1→5 흐름 인포그래픽)와 같은 편집 톤.

**생성 프롬프트 (영문, 복붙용):**
```
A horizontal 4-step process infographic, clean flat vector + semi-realistic illustration, white/ivory background, palette deep navy #0B3D4F + teal #126E82 + orange #E8722C. Four numbered stages left-to-right connected by orange arrows, each stage a titled illustration:
STAGE 1 "Diagnose": a satellite, a drone, and an underwater camera scanning a coastal rocky seabed; part of the seabed is barren white rock, part is teal kelp.
STAGE 2 "Prescribe": the same seabed shown as a map split into color-coded cause zones (red/orange/purple), with three small prescription icons — urchin removal, heat-tolerant seaweed sprout, substrate cleaning.
STAGE 3 "Verify (MRV)": a before/after pair — bare white rock transforming into a lush teal kelp forest with small fish returning; a paired-plot comparison and a small rising line chart.
STAGE 4 "Carbon Credit": a restored kelp forest converting into a carbon-credit certificate / coin icon, with a small coastal village receiving benefit.
Numbered badges 1-2-3-4 across the top. Thin lines, professional editorial infographic, generous whitespace, no neon, no heavy shadows, poster-quality, high detail.
```

**얹을 한글 라벨:**
- 제목: **켈피 — 죽은 바다를 되살려 탄소자산으로**
- 상단 흐름: `① 진단` → `② 처방` → `③ 검증(MRV)` → `④ 크레딧`
- 단계 캡션:
  - `① 진단 — 위성·드론·수중영상으로 '왜 죽는지' 원인 지도화`
  - `② 처방 — 원인별 맞춤 복원(성게 제거·내열종·기질 처리)`
  - `③ 검증 — 처방군 vs 대조군 정착률 실측, 정말 살았는지 증명`
  - `④ 크레딧 — 검증된 탄소흡수량을 블루카본 크레딧·바다연금으로`
- 하단 한 줄: `보이지 않던 두 가지 — 왜 죽는지, 정말 살았는지 — 를 처음으로 보이게 한다`

## ✅ 사용 순서 요약
1. 위 **공통 스타일 가이드**를 먼저 붙여 톤을 고정.
2. 이미지별 **영문 프롬프트**로 (텍스트 없이) 일러스트 생성 — 여러 장 뽑아 베스트 선택.
3. **한글 라벨**을 Canva/PPT/Figma로 얹기(팔레트·폰트는 맑은 고딕/프리텐다드 권장).
4. OpenTrap 이미지 2장과 나란히 놓고 **팔레트·굵기·여백이 같아 보이는지** 최종 대조.

> 참고: OpenTrap 이미지1(엔지니어링 조립도)에 대응하는 '기술 신뢰' 이미지가 더 필요하면,
> **이미지1(대시보드)** 을 그 역할로 쓰면 충분하다(켈피는 SW라 조립도 대신 제품 UI가 신뢰 근거).
