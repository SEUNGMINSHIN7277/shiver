# 🧑‍⚖️ 5인 심사위원단 — 2026 해양수산 창업 콘테스트(아이디어 부문)

우리 아이디어 3개를 **객관적·냉정하게** 사전 채점하기 위한 가상 심사위원단이다.
공고의 실제 배점과 역대 수상 패턴에 근거해, 서로 다른 관점의 심사위원 5인을 구축하고, 그들로 우리 아이디어를 채점·비교·보완하는 도구 세트다.

> **왜 만드는가**: 예선은 100% 서류심사이고, 아이디어 부문 혁신성이 배점의 60%를 차지한다. 제출 전에 "박한 심사위원 5명"에게 미리 두들겨 맞아 두는 것이, 실제 심사에서 두들겨 맞는 것보다 싸다.

## 👥 심사위원 5인 요약

| # | 코드네임 | 관점 | 지배 축(배점) | 한 문장 |
|---|---|---|---|---|
| J1 | **도해심** | 해양수산 도메인·기술(KIMST/대학 R&D) | 기여도·실현(기술) | "정말 *해양수산* 문제를, *기술적으로* 푸는가?" |
| J2 | **배투자** | VC/액셀러레이터 투자심사역 | 사업성·사업화 | "시장이 있나, 돈을 버나, 왜 지금·왜 당신인가?" |
| J3 | **문혁신** | 혁신성·창의성·IP 심사 | 아이템 가치(혁신성 60) | "진짜 새로운가, 검색하면 나오나?" |
| J4 | **정공공** | 해수부·정책·공공가치 | 기대효과·정책정합 | "국가 아젠다에 맞고, 세금 쓸 가치가 있나?" |
| J5 | **현산업** | 후원사·현장·금융(수협/해운/IBK) | 실현(현장)·실행 | "현장에서 쓰나, 팔리나, 대출·보증 되나?" |

5인은 배점 4축(아이템 가치·사업성·기대효과·역량)과 두 시점(예선=참신함 / 최종=실현·사업화)을 **겹치되 서로 견제**하도록 설계됐다. 전원 기본값은 **회의(입증 안 되면 점수 없음)**다.

## 🚀 빠른 시작 (3개 아이디어 채점)

1. **개요서(또는 요약) 준비** — 아이디어별로 텍스트. *빈 칸은 채우지 말 것(빈 칸 = 채점 대상).*
2. **5인 독립 채점** — `03_심사위원_5인.md`의 시스템 프롬프트 5개를 **각각 별도 세션**에 넣고 같은 개요서를 붙인다.
3. **집계** — `04_채점시트.md`의 표에 5인 점수를 옮기고, ①담당가중 평균 ②최저 심사위원 점수 ③편차 ④미답 질문 수를 산출.
4. **판정·보완** — 판정 밴드로 3개 아이디어 순위를 매기고, 중복 지적 순으로 보완 우선순위를 뽑는다. 미답 저격 질문 = 발표 예상 Q&A.

> **더 쉬운 길**: 아이디어 3개를 이 세션 채팅에 공유하면, 5인 페르소나로 직접 채점해 `04_채점시트.md`의 시트를 채워 드립니다.

## ⚠️ 한계 (정직하게)

- 실제 심사위원 실명·배점표는 공개되지 않는다. 이 5인은 대회 구조와 공개 수상 패턴에서 **역산·재구성**한 것이며 실제 인물과 1:1 대응하지 않는다.
- 역대 수상작 목록은 공개 보도·언론 기반이라 일부 표기 오차 가능(경향 도출에는 충분).
- 결과는 **의사결정 보조**다. 냉정한 사전 점검용이지, 실제 수상 예측이 아니다.
