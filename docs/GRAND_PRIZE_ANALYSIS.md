# 대상권 판정 분석 (냉정판)

작성: 2026-07-12 · 목적: 심사위원 관점에서 K-Rosetta가 대상권인지 냉정하게 판정하고, 부족분을 명확히 짚어 보완

---

## 1. 판정 방법론

세 가지 기준으로 교차 판정한다.
1. **공고 심사기준 6축**: 공공데이터 활용 · AI 기술 활용 · AI 서비스 · 독창성 · 발전가능성 · ESG혁신
2. **역대 수상 패턴**: 외교부 대회 최우수작(2023 오셜, 2024 스페이스인사이트, 2025 SafetyCraft)은 해외안전·ODA 집중 → 문화·언어는 공백. 범정부 대통령상 QLAUDIO는 "문화 공공데이터 × AI".
3. **레드팀(반론)**: 심사위원이 던질 가장 날카로운 질문에 방어되는가.

| # | 예상 질문 | 방어 가능? | 대응 |
|---|---|---|---|
| Q1 | "GPT/파파고면 되잖아?" | ✅ | 저자원 언어 문화용어에서 일반 MT 12.5%. 데모로 직접 증명. |

| Q5 | "사업화 근거는?" | ⚠️→보완 | 시장 규모·파일럿 계획 구체화(G3). |

## 4. 대상권에 미치지 못하는 명확한 이유 (Gap)

### G1. AI 기술 깊이 — 검색이 키워드(FTS) 기반 [보완 대상]
- 현재 RAG 검색이 SQLite FTS(키워드 매칭). "판소리 비슷한 공연예술"처럼 **의미가 유사하지만 단어가 다른** 질의를 못 잡는다.
- 보완: 다국어 문장 임베딩(BGE-M3 계열)으로 **의미 기반 검색** 적용 → "AI 기술 활용" 축 3.0→4.5.

### G2. 임의 문장 완역이 캐시 기반 [정직 프레이밍 + 라이브 옵션]
- DEMO_MODE=cached에서 완역은 프리셋만. 임의 문장은 용어 카드(표준 대역)까지만.
- 보완: (a) 핵심 가치인 **용어 충실도는 임의 입력에서도 동작**함을 전면화, (b) 발표 시 소액 충전으로 라이브 완역 시연(코드는 완비).

### G3. 실증 트랙션 0 [사업계획 구체화]
- 역대 최우수작은 '출시 예정'(SafetyCraft)·'매출 4천만원'(QLAUDIO) 같은 실증이 있었다.
- 보완: 시장 규모(웹툰 수출액·번역 인건비 병목) 정량화 + B2B 파일럿 제안 구체화. 발표 전 실제 파일럿 1건 접촉 권장(사용자 액션).

### G4. 벤치마크 지표의 순환성 [정직 재정의]
- '정확도 100%'는 자기 사전 기준이라 순환 논리로 보일 수 있다.
- 보완: **'KF 공인 표준 표기 준수율'**로 재정의(측정하는 것을 정확히 명명). 일반 번역기가 공공데이터 표준을 얼마나 따르는지 vs 우리가 강제하는지 — 이건 순환이 아니라 정당한 비교.

## 5. 보완 실행 결과 (본 세션)

- [x] **G1: 교차언어(cross-lingual) 검색 적용** — 다국어 임베딩 모델(BGE-M3) 다운로드가 원격 환경에서 차단(HuggingFace 403)되어, 대안으로 **용어사전 기반 질의 확장기**를 구현(`search.py`의 `expand_query`). 외국어·로마자 질문에서 문화용어를 인식→한국어 표제어로 확장 후 코퍼스 검색. 검증: 영어 "hanji paper craft" → 한국어 Koreana 기사 검색 성공. 이는 저자원 언어 사용자가 자국어로 물어도 한국어 근거를 찾게 하는 **실질적 교차언어 검색**이며, 자원 제약(비용 0원 원칙) 내에서 의미검색의 핵심 효용을 확보.
- [x] **G4: 벤치마크 지표 재정의** — '정확도'→**'공인 표준 표기 준수율'**로 명명 변경(`build_benchmark.py` `metric_name`, 프론트 `app.js`, 기획서 MD/HTML 전면 반영). 방법론에 "100%는 표준 강제에 의한 설계값, 핵심은 일반 번역기의 23%대 준수율"을 명시해 순환 논리 반론을 정면 방어.
- [x] **G3: 사업계획 시장성 보강** — 기획서에 '시장성 및 사업 필요성' 절 신설(1차 로컬라이제이션 / 2차 기관 다국어 / 3차 데이터 라이선스 시장, 진입 근거). 실증 트랙션은 발표 단계 파일럿 접촉으로 이관(정직 기재).
- [x] **G2: 데모 서사 정리** — '용어 충실도는 임의 입력에서도 동작, 완역 생성은 라이브 옵션'을 기획서·화면 안내에 명시. 캐시 모드가 비용 0원 원칙에 따른 의도적 설계임을 문서화.

### 정직한 최종 결론
- **위치**: **확실한 최우수(우수)권, 대상권 경합 가능**. 이 대회의 1순위 축인 '공공데이터 활용'에서 최상위(8종을 엔진으로 실사용)이고, '독창성'에서 경쟁 부재 — 이 두 축이 대상 후보의 핵심 근거다.
- **대상을 100% 담보하지 못하는 잔여 요인 (정직하게)**:
  1. **실증 트랙션 0** — 역대 대상·최우수작 다수가 실사용자/매출/출시예정 같은 증거를 가졌다. 본작은 발표 전 B2B 파일럿 1건 접촉이 있으면 판정이 크게 개선된다(**사용자 액션 권장**).
  2. **완전한 의미검색 미탑재** — 비용 0원·네트워크 차단 제약으로 임베딩 대신 용어사전 질의 확장을 택했다. 유료 전환 승인 시 BGE-M3 임베딩으로 격상 가능(코드 골격 준비됨).
  3. **완역 라이브 미시연** — 캐시 모드가 기본. 발표장에서 소액 충전 라이브 완역을 1회 시연하면 G2가 완전히 해소된다.
- **판정**: 제출 상태로 **최우수권은 확실**하며 대상은 발표 시연 품질과 위 3개 잔여 요인의 현장 보강에 달렸다. 서면 심사만으로는 상위권 진입에 충분하나, 대상 확정을 위해서는 발표 단계의 실증(파일럿·라이브 시연)이 결정적이다.
