## 제품 또는 서비스 개요

한류 콘텐츠가 세계로 나갈 때 '한지·판소리·선배·재벌' 같은 **문화 용어는 일반 번역기에서 체계적으로 붕괴**된다. K-Rosetta는 외교부 산하기관이 축적해 온 공공데이터(음식 표준명, ODA 용어, KF 발간 자산)를 AI 번역의 **용어 제약(constrained translation)** 으로 강제하여, 문화 용어의 충실도를 지키는 번역·설명 서비스를 제공한다. 자체 벤치마크(64케이스×4개 언어) 실측 결과 일반 번역기의 표준 용어 충실도는 평균 23.4%(베트남어·인도네시아어 12.5%)에 그친 반면, K-Rosetta는 100%를 기록했다. **실동작 데모가 이미 완성되어 있다.**

## 1. 제품 또는 서비스의 목적 또는 배경

**세계는 한국을 좋아한다. 그러나 세계가 읽는 한국은 자주 틀려 있다.**

- 웹툰·OTT·K-pop 등 K-콘텐츠 수출은 확대 중이나, 로컬라이제이션(현지화)이 병목이다. 특히 '오빠'가 "anh trai(친오빠)"로, '떡국'이 "rice cake soup"로 뭉개지는 **문화 용어 붕괴**는 한국 문화가 세계에 잘못 전달되는 공공외교 문제이자, 콘텐츠 수출 품질 문제다.
- 저자원 언어(베트남어·인도네시아어·아랍어·러시아어)일수록 붕괴가 심하다 — 자체 실측에서 일반 번역기의 문화용어 표준 충실도는 영어 33.9% → 러시아어 20.8% → 베트남어·인도네시아어 12.5%로 급락했다. 그런데 이 언어권이 바로 한류 수요가 가장 빠르게 성장하는 지역이다.
- 한편 외교부 산하기관에는 이 문제를 풀 열쇠가 이미 축적되어 있다: KF가 1987년부터 11개 언어로 발간해 온 《Koreana》(전문 번역가들이 39년간 확립한 문화용어 역어 관례), KF 한국음식정보(공인 영문 표준명), KOICA ODA 용어사전. **아무도 이것을 AI 번역 자원으로 결합한 적이 없다.**
- K-Rosetta의 목적: 잠자던 외교부계열 공공데이터를 깨워, ① 한국 문화가 세계 언어로 **정확히** 옮겨지게 하고(공공외교), ② K-콘텐츠 수출의 로컬라이제이션 병목을 해소한다(문화→경제).

## 2. 제품 또는 서비스의 기능 및 특징

**[그림1: 번역 비교 화면 — 01_translate_compare.png]**

### 기능 1 — 문화 로컬라이제이션 번역 엔진
- 입력 문장에서 문화 용어를 자동 탐지하고, 공공데이터 표준·KF 관례 대역을 **강제 적용**해 번역
- 결과 화면에서 용어별 근거 카드 제공: 채택 대역, 정의, **데이터 출처(공공데이터포털 데이터셋명·번호)** 명시
- '일반 번역기와 비교' 모드: 용어사전 미적용 번역과 나란히 표시 — 차이가 즉시 보인다
  (예: 떡국 → 일반 번역기 "rice cake soup" vs K-Rosetta "Sliced Rice Pasta Soup" — KF 공인 표준)

### 기능 2 — K-콘텐츠 자막·대사 모드 (업계 실무 워크플로)
**[그림2: 자막 모드 화면 — 04_subtitle_mode_vi.png]**
- 웹툰·OTT 자막 번역 관례(첫 등장 시 음차+간결 주석, 재등장 시 음차만)를 모드로 구현
- 호칭·사회문화 어휘(선배·막내·재벌·갑질·눈치·전세 등) 전용 사전 — 일반 번역기가 "em út(친동생)"으로 뭉개는 '막내'를 "maknae(그룹의 최연소 멤버)"로 지켜낸다
- 드라마 대사·웹툰 컷 데모 시나리오 내장

### 기능 3 — 다국어 문화 설명 챗봇 (근거 인용 RAG)
**[그림3: 챗봇 화면 — 02_chat_citations.png]**
- "Что такое 온돌?"(러시아어), "Apa itu gimjang?"(인도네시아어) — 질문 언어를 자동 감지해 그 언어로 답변
- 모든 답변에 **KF 공공데이터 코퍼스의 출처 문서를 인용** — 환각 없는 근거 기반 설명
- 저자원 언어권 한류 팬(2020년 기준 전 세계 한류 동호회원 1억 명+, KF 지구촌 한류현황)이 1차 사용자

### 기능 4 — K-Rosetta 벤치마크 (공개 평가셋)
**[그림4: 벤치마크 대시보드 — 03_benchmark.png]**
- 문화용어 64케이스 × 4개 언어에서 "일반 번역기 vs K-Rosetta"의 표준 충실도를 공개 비교
- 채점 기준·방법론·일반 번역기가 정답인 사례까지 전부 공개하는 **정직한 벤치마크** — 문화용어 번역 품질의 국가 표준 평가셋으로 발전 가능

### 기술 구성
- 용어사전 1,177개(문화 138·음식 691·ODA 419) × 다국어 대역 1,575개(영·베·인니·아랍·러) — 전량 공공데이터 및 KF 간행물 관례 기반
- 검색(FTS) 기반 RAG + 용어 제약 LLM 번역(Claude API, 프롬프트 캐싱·배치 최적화 설계) + 경량 SQLite 스택
- 전 기능이 로컬 실행 가능한 데모로 구현 완료 (오프라인 시연 대비 캐시드 모드 내장)

- **데이터가 장식이 아니라 엔진이다**: 공공데이터의 표준 용어가 번역 출력을 직접 결정하고, 서비스 화면 하단에 데이터셋명·건수·포털 링크를 상시 노출한다.
- **확보의 지속성**: 핵심 3종은 인증키 불요 파일데이터(연 단위 갱신), API 3종은 활용신청 승인 완료(일 트래픽 10,000). 《Koreana》는 KF 공개 웹진으로, 파생 데이터(용어 대역·통계)만 활용하고 원문은 재배포하지 않으며 상업화 단계에서 KF와 이용 협의를 전제한다.
- **가공**: 표준명 정규화 → 다국어 대역 정렬 → 용어 제약 번역 프롬프트 → 근거 인용, 전 과정 재현 가능한 파이프라인으로 공개.

## 4. 기존 제품(서비스)과의 차별성 및 독창성

1. **경쟁 공백(white space)**: 문화 용어 충실도를 목표 함수로 삼는 번역 서비스는 국내외에 없다. 구글·파파고·GPT는 범용 정확도를 다투지만, 문화 용어의 '공인 표준 준수'는 측정조차 하지 않는다.
2. **데이터 해자**: KF 39년 × 11개 언어 발간 자산 + 공공데이터 표준명 — 후발 주자가 복제할 수 없는 공공 코퍼스 조합. (작년 범정부 대회 대통령상 QLAUDIO가 국립국악원 음원으로 증명한 "잠자던 문화 공공데이터 × AI" 공식과 동일 구조, 소재는 미개척)
3. **실측 격차**: 동일 조건 비교에서 일반 번역기 23.4% vs K-Rosetta 100% (문화용어 표준 충실도, 64케이스×4개 언어). 저자원 언어에서 격차 최대 — 한류 성장 지역과 정확히 겹친다.
4. **정직한 방법론**: 채점 기준·실패 사례·일반 번역기가 정답인 케이스까지 공개. 벤치마크 자체가 재사용 가능한 공공 자산.
5. **업계 워크플로 내장**: 자막 모드(첫 등장 주석/재등장 음차)는 로컬라이제이션 실무자의 실제 작업 관례 — 데모가 아니라 도구다.

## 5. 기대효과

- **공공외교(외교부 미션 직결)**: 한국 문화가 11개 언어권에 왜곡 없이 전달 — '설명당하는 한국'에서 '스스로 정확히 설명하는 한국'으로. 2026.6 외교부-문체부 K-컬처 ODA 협력 기조와 정렬.
- **문화→경제**: K-콘텐츠 수출의 로컬라이제이션 품질·속도 병목 해소. 번역가 대체가 아닌 **용어 검수 자동화**로 전문 번역가의 생산성을 높이는 상생 구조 — 신규 직무(문화용어 데이터 큐레이터) 창출.
- **공공데이터 생태계**: 사장되어 있던 KF·KOICA 데이터의 첫 AI 자원화 사례 + 문화용어 다국어 평가셋(벤치마크)을 공공에 환원.
- **ESG·포용**: 저자원 언어권(동남아·중동·러시아어권) 사용자의 한국 문화 정보 접근성을 고자원 언어 수준으로 — 문화 다양성과 정보 형평.

## 6. 제품 및 서비스의 사업(창업) 계획

- **단계 1 (현재~'26.9)**: 데모 고도화 — Koreana 아카이브 정렬로 용어사전 500+ 확장, 11개 언어 커버리지, LLM-judge 벤치마크 v2. KF에 데이터 활용 협력 제안(공문).
- **단계 2 ('26.4Q)**: B2B 파일럿 — 웹툰·자막 로컬라이제이션 업체 2곳에 용어 검수 API 무상 파일럿, 박물관·관광공사에 다국어 문화 설명 위젯 제안.
- **단계 3 ('27)**: 수익화 — ① 로컬라이제이션 SaaS/API 구독(용어 검수·자막 모드), ② 기관용 다국어 문화 챗봇(박물관·관광·재외문화원), ③ 문화용어 데이터 라이선스. 예비창업패키지·글로벌 진출 지원사업 연계.
