## 핵심 검증 사실 (사업계획서 인용 가능)
- '한국의 장 담그기 문화' = **2024.12 UNESCO 인류무형문화유산** 등재(김장 이후 두 번째 K-음식문화, 한국 23번째 유산)
- '장 담그기' = **국가무형유산 제137호**(2018)
- **기순도 명인(식품명인 35호)의 370년 종가 씨간장 → 2017 트럼프 국빈만찬 메인 소스**
- 2024 K-Food 수출 $130.3억(미국 1위 시장) / 소스류 수출 $399.76M 역대최대
- 화이트스페이스: "정부 인증 명인 × 종가 수백년 × UNESCO × 웰니스 × 글로벌 프리미엄 D2C" 결합 브랜드 **부재**
- 실현성: 공장 없이 **유통전문판매업 + 명인 OEM 위탁**으로 창업 가능
