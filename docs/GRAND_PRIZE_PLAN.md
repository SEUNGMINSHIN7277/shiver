## 2. 심사 5축 대비 고도화 우선순위 (전부 비용 0원)

- **P1. K-콘텐츠 로컬라이제이션 모드** ← 독창성·사업성 축의 결정타
  - 용어사전에 **호칭·사회문화 도메인** 추가 (오빠/언니/선배/재벌/전세/회식/찜질방 등
    웹툰·OTT 번역 실무가 실제로 깨지는 용어) — 어떤 경쟁 서비스에도 없는 자산
  - `domain=subtitle` 모드: 자막 업계 관례(첫 등장 "음차+간결 설명", 재등장 음차만) 구현
  - 데모 시나리오: 드라마 대사·웹툰 컷 텍스트
- **P2. 저자원 언어 벤치마크 v1** ← 기획서 킬러 데모 + "GPT면 되잖아" 레드팀 방어
  - vi/id/ru 문화용어 케이스 추가, 언어×시스템 요약 매트릭스
- **P3. UI 완성도** ← 발표평가 + 범정부 국민평가단(직관성) 대비
  - 입력·결과 용어 하이라이트, 러시아어 지원, 자막 모드 토글, 히어로 실데이터 지표
- **P4. 다국어 챗봇 응답** — 질문 언어(vi/id/ar/ru) 감지 → 해당 언어 대역+설명으로 응답
- **P5. 접수 기획서(붙임3) 초안** ← **마감 7/13 18:00, 최우선 산출물**
- P6(대기). Koreana 파일럿 도착 시: 용어 근거 연결·코퍼스 확장·병렬 정렬 v1 (스크립트 준비 완료)

## 3. 성공 판정 기준 (이 세션의 DoD)

- [ ] 용어사전 ≥ 100 문화용어 × 5개 언어(en/vi/id/ar/ru), K-콘텐츠 도메인 신설
- [ ] 자막 모드 API+UI+프리셋 동작, 스크린샷
- [ ] 벤치마크 ≥ 60케이스(en+vi+id+ru), 언어별 요약, UI 필터
