# 대표님 확인 필요 — 월요일 발표 준비 체크리스트

> 발표 자료를 정확히 만들기 위해 **대표님만 답할 수 있는** 항목입니다.
> 답이 오는 대로 슬라이드·수치자료에 즉시 반영합니다.

## A. 발표의 성격 (가장 중요 — 자료 방향이 여기서 갈림)
- [ ] **A1.** 7/20(월) 자리가 "협약식·오리엔테이션"인데, 그 안에서 **발표(브리핑)**를 하는 것이 맞나요? 아니면 별도 발표 요청을 받으셨나요?
- [ ] **A2.** 발표 **시간**은 몇 분인가요? (5분 / 10분 / 자유)
- [ ] **A3.** **청중**은 누구인가요? (심사위원 / 운영사(13컴퍼니) / 재단 담당자 / 타 선정 4팀 / 혼합)
- [ ] **A4.** **형식**은? (슬라이드 PPT / 구두 / 한쪽 요약본 제출 / 데모)
- [ ] **A5.** 운영사가 **미리 제출하라고 한 자료·양식**이 있나요? (있으면 그 양식에 맞춤)

## B. 수요처 증빙 (3-1 보강용)
- [ ] **B1.** 콜드메일 **긍정 회신 2곳**의 업종·규모와, 지금 어느 단계인가요? (회신 원문 캡처 가능한가요?)
- [ ] **B2.** 월요일 전에 **의향서(LOI) 1건** 또는 **미팅 약속**을 받아낼 수 있는 상대가 있나요? (인근 게스트하우스/상인회장 등)
- [ ] **B3.** 협력할 **전통시장**은 정해졌나요? 상인회 접촉 이력이 있나요?

## C. 고용·급여 (3-2 보강용)
- [ ] **C1.** **고용 주체**를 무엇으로 하실 생각인가요? (개인사업자 / 팀 법인 / 협동조합 / 미정)
- [ ] **C2.** 팀 구성은? (제안서상 대표+팀원①(촬영)+팀원②(예약·통역)) — 실존 팀원인가요, 채용 예정인가요?
- [ ] **C3.** 청년 통역 서포터는 이미 있는 인력인가요, 별도 모집인가요?

## D. 매출·자원 (3-3 보강용)
- [ ] **D1.** 실제로 노리는 **플랫폼**은? (에어비앤비 체험 / 마이리얼트립 / 크리에이트립 / 기타) — 수수료율 확인용
- [ ] **D2.** **B2B 단체** 체험을 연결할 수 있는 접점(기업·기관)이 있나요?
- [ ] **D3.** 대표님이 직접 진행 가능한 **외국어(영어 등) 수준**은? (발표에서 실행력 근거로 쓸 수 있음)

## E. 자료·브랜딩
- [ ] **E1.** 발표 자료에 쓸 **사진**(시장·음식·시니어 관련)이 있나요? 없으면 텍스트·아이콘 중심으로 구성.
- [ ] **E2.** 슬라이드 **언어**는 국문으로 진행하면 되나요?

---
*답변은 항목 번호로 주셔도 됩니다. 예: "A2=10분, A3=심사위원+운영사, C1=개인사업자".*
