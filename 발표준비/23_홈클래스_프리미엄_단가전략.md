# 홈 쿠킹클래스 단가 올리기 — 프리미엄 전략 (시장동행 없이)

> 질문: 집에서 쿠킹클래스만 하고 시장동행을 뺄 때, 단가를 높이는 방법은?
> ## 핵심
> **시장투어 = '수평 확장(더 넣기)'. 프리미엄 = '수직 심화(더 깊게·고급)'. 집은 수직으로 간다.**
> **실측: 한옥 프리미엄 쿠킹클래스는 시장투어 없이도 이미 $87~94(12~13만원)** → **Case 1의 134,900원은 근거 있는 가격.**

---

## 1. 데이터 검증 — 프리미엄은 이미 팔리고 있다 (시장투어 없이)
| 상품 | 단가 | 구성 |
|---|---|---|
| Royal Seoul Cooking Class in 100년 한옥 | **$94(약 13만원)** | 궁중요리(LA갈비·김치·파전·탕평채), 6명 한정, 개인 조리대 |
| Korean Premium Cooking Class in 북촌 한옥 | **$87(약 12만원)** | 재료·장비·식사·음료 포함, 2~4명 소수정예 |
| 에어비앤비 "Local's Hanok Home" 클래스 ★5.0 | 프리미엄 | 진짜 한옥 가정 |
→ **시장투어 없이도 '한옥+궁중요리+소수정예'로 12~13만원.** Case 1 단가 정당성 확보.

## 3. 마진 관점 — 대부분 '고마진' 레버다
- **원가 0에 가까운 레버:** 한옥/홈 setting(집 자체), 한복(재사용), 스토리·다도·예절(인건비만), 사진.
- **원가 있으나 가격이 더 오르는 레버:** 궁중요리·프리미엄 재료, take-home. → **순마진 증가.**
- → 단가를 올리는 대부분의 방법이 **마진도 함께 올린다.** (시장투어보다 프리미엄 심화가 수익성에 유리)

## 4. 우리 상황 맞춤 추천
### 집이 한옥이면(종로·북촌·서촌)
→ **①한옥 + ②궁중/프리미엄 메뉴 + ③한복 + ⑤소수정예 + ⑥take-home** 스택 = **12~15만원** 정당.
### 집이 일반 주택이면
→ 한옥 프리미엄이 없으니 **홈스타일 연출 + ②프리미엄 메뉴 + ③한복 + ④막걸리 빚기 + ⑥굿즈**로 **9~12만원** 목표.

### ★입지 전략 연결
- **프리미엄 홈 tier = 종로·북촌·서촌 한옥** (한옥이 최대 프리미엄 드라이버).
- 표준 공유주방 tier = 연남·망원(8번 문서). → **tier별로 입지가 다르다.**

## 5. 트레이드오프 주의
- **소수정예(2~4명)로 가면 정원↓ → 회당 매출이 단가 상승분으로 상쇄돼야 함.** 프리미엄 comp($87~94 × 2~6명)는 고단가로 이를 맞춤. 우리 경제성 모델(5~7명 가정)과 다르므로, **소수정예 프리미엄은 별도 시나리오로 계산 필요.**
- 프리미엄 재료·한복·굿즈는 **초기·회당 원가**가 늘므로 P&L에 반영.

## 6. 발표 한 줄
> **"시장동행을 빼도, 한옥·궁중요리·한복·소수정예로 '수직 프리미엄'을 쌓으면 오히려 단가가 올라갑니다 — 실제로 서울 한옥 쿠킹클래스는 시장투어 없이 12~13만원에 팔리고 있습니다."**
