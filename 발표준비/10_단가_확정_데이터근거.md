# 쿠킹클래스 단가 — 데이터 기반 확정 (각 항목 근거 명시)

> 모든 입력값을 **실제 시세·법정기준**으로 고정하고 손익을 계산. (스크립트 `pricing_final.py`)
> 세 질문에 대한 답: **공유주방=회당 75,000원(연남 실측) / 호스트=시급 15,000원·회당 55,000원 / 외국인=인당 65,000원.**

## 1. ✅ 확정 입력값 (각 숫자의 근거)

| 항목 | 확정값 | 데이터 근거 |
|---|---|---|
| **외국인 인당 단가** | **65,000원** | 얌이랩 평일45k·주말60k / 글로벌 플랫폼 5~9만 → **comp 중심가** |
| **호스트 시급** | **15,000원/h** | 2026 최저임금 10,320 · **2026 서울 생활임금 12,121** → 둘 다 상회(1.24배) |
| **호스트 회당임금** | **55,000원/회** | 시급 15,000×3h(준비0.5+진행2.5)=45,000 + 진행수당 10,000 |
| 청년 서포터 | 40,000원/회 | 시급 약13,000×3h (생활임금 상회, 이중언어) |
| **공유주방(시범)** | **75,000원/회** | 연남 25,000/h × 3h (**다르다 스튜디오 실측**, 스페이스클라우드) |
| 공유주방(정착) | 40,000원/회 | 망원시장/식당/공공주방 제휴가 |
| 식재료 | 9,000원/인 | 시장 당일조달 한 끼 완식 |
| 소모품·가스·수도 | 8,000원/회 | |
| 플랫폼 수수료 | 15% | 에어비앤비20% + 마리트/클룩15~18% + 직판0% blended |

## 2. 회당 손익 분해 (외국인 65,000원 · 정원 5명 · 시범 공유주방)

| 단계 | 금액 | 누계 |
|---|--:|--:|
| ① 매출 (65,000×5) | +325,000 | 325,000 |
| ② 플랫폼 수수료 15% | -48,750 | 276,250 |
| ③ 식재료 9,000×5 | -45,000 | 231,250 |
| ④ 청년 서포터 | -40,000 | 191,250 |
| ⑤ 공유주방(시범) | -75,000 | 116,250 |
| ⑥ 소모품 | -8,000 | 108,250 |
| ⑦ 호스트(이모) 임금 | -55,000 | 53,250 |
| **= 운영주체 회당 이익** | | **+53,250 ✅** |

## 3. 손익분기 정원 (운영주체 흑자 최소 인원)
| 가격 | 시범주방(75k) | 정착제휴(40k) |
|---|--:|--:|
| 55,000 | 4.7명 | 3.8명 |
| **65,000** | **3.8명** | **3.1명** |
| 75,000 | 3.3명 | 2.6명 |
→ **65,000원이면 시범 단계에도 4명이면 흑자.**

## 4. 월간 — 호스트 소득 vs 서울 생활임금 (65,000원 · 정원 5명)
| 공간 | 월 17회 | 월매출 | 호스트 소득 | 시급환산 | 운영주체 이익 |
|---|--:|--:|--:|--:|--:|
| 시범(75k) | 17회 | 5,525,000 | **935,000** | 18,333원 | **+755,250** |
| 정착(40k) | 17회 | 5,525,000 | **935,000** | 18,333원 | **+1,350,250** |

- **서울 생활임금 시급 12,121원**, 파트타임(월 51h) 환산 ≈ 618,171원.
- **우리 호스트: 월 935,000원(시급환산 18,333원) → 서울 생활임금을 크게 상회.** = "정당한 임금" 근거로 강력.
- 급여가 **지원금이 아니라 매출로** 지급됨(운영주체도 흑자) → 지원금 종료 후 지속가능.

## 5. 수수료·채널 민감도 (65,000·5명·시범주방)
| 채널 | 수수료 | 회당 운영이익 |
|---|--:|--:|
| 직판/게하/B2B | 0% | +102,000 |
| blended | 15% | +53,250 |

→ 전 채널 흑자. **직판·B2B↑ = 마진 2배.**
