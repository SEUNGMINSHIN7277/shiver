# 쿠킹클래스 단독 코스 — 최적 입지 선정 (뾰족한 결론)

> 질문: 내·외국인 대상 '할머니 손맛' 쿠킹클래스를 **어디서** 열까? (외국인 집객 + 대여 공유주방 실재 + 이동 리스크 + 진정성 종합)
> ## ✅ 결론: **마포구 연남동·망원 일대 (홍대입구역 기점)**
> 시범 공간은 **연남/망원의 시간제 쿠킹 공유주방**(실재·풍부·저비용)으로 시작 → 정착 후 **망원시장 안/인근 상설공간·식당 제휴**로 이전.

## 1. 쿠킹클래스 입지의 6대 기준
| # | 기준 | 왜 |
|---|---|---|
| A | 외국인 집객·명소성 | 손님이 찾아와야 함 |
| B | **대여 가능한 공유주방 실재** | 시범 단계에 빌릴 공간이 실제로 있어야 함(하드 요건) |
| C | 이동 리스크(교통 단순·안전) | 외국인이 헤매지 않고 안전하게 |
| D | 진정성·로컬 식재료(전통시장 인접) | 브랜드 + 당일 장보기 원가·상생 |
| E | 내국인 2030 집객 | 주말 내국인 클래스 병행 |
| F | 시니어 호스트 거주 | 토박이 이모 확보 |

## 3. 🥇 왜 연남·망원인가 (근거)

**A·B. 외국인 집객 + 공유주방 공급이 동시에 최고**
- **공항철도 홍대입구역 = 인천공항 직통(약 53분, 2~4달러).** 외국인 이용 최다 노선이고, **홍대입구역 외국인 유동은 토요일이 월요일의 1.5배** — 주말 외국인 관광 수요가 몰림.
- **빌릴 공유주방이 실재하고 풍부:** 공간대여 플랫폼(스페이스클라우드 등)에 **연남/홍대 시간제 쿠킹스튜디오·공유주방 매물 다수** (예: 연남 '다르다 스튜디오' 시간당 25,000원·최소 2시간, 홍대 쿠킹스튜디오 스토리라운지, 베이킹·쿠킹 공유주방). **1~2시간 단위 예약 가능 → 시범 단계 저비용·유연.**
- → 인사동은 외국인 쿠킹클래스 '기존 집적지'지만 대부분 **자체 스튜디오 보유 업체**라 **시간제로 빌릴 공유주방 공급이 얇고 임대가 비쌈**. 우리처럼 시범으로 빌려 시작하기엔 연남이 압도적.

**C. 이동 리스크 최저**
- 홍대입구역 = **2호선·공항철도·경의중앙선 3개 노선 환승** 대형역. 짐 들고 공항에서 바로 옴.
- 집결 랜드마크가 명확(홍대입구역 3번 출구 '연트럴파크') → 외국인이 못 찾을 수 없음. 망원까지 한 정거장.

**D. 진정성·식재료·상생**
- **망원시장**은 비지트코리아에도 등재된, **외국인 관광객까지 찾는 매력적 전통시장**(전통 먹거리 + 카페·디저트로 현대적 분위기). **쿠킹 재료를 당일 시장에서 조달** → 원가 절감 + 진정성 + 시장 상생. (쿠킹·투어를 분리해도 "이모의 시장에서 온 재료"라는 연결 유지.)

**E·F. 내국인 + 시니어**
- 연남·홍대는 **내국인 2030 성지** → 주말 '할머니 집밥' 클래스 병행에 최적.
- 망원·성산동 오래된 주거지에 **토박이 시니어** 거주 → 호스트 확보 가능. (50플러스 서부캠퍼스가 마포·서대문 담당 → 모집 연계.)

## 4. 🥈 인사동·종로를 2순위로 두는 이유
- 장점: 외국인 쿠킹클래스 **검증된 집적지**(Seoul Cooking Club = 인사동·명동·경복궁 도보권, Museum Kimchi = 인사동), 궁궐·전통 명소, 광장시장.
- 단점: ① **시간제 대여 공유주방 공급 부족**(자체 스튜디오 업체 위주) ② **임대·물가 높음** ③ **유사 업체 포화 = 경쟁 치열** ④ 내국인 2030 매력 낮음 ⑤ 과잉 관광화로 '진짜 로컬' 차별성 약화.
- → 검증된 수요는 매력적이나, **시범사업의 저비용·차별성·공간확보 관점에서 연남이 유리**.

## 5. 구체 실행안 (연남·망원 기준)
| 항목 | 실행 |
|---|---|
| **집결지** | 홍대입구역(공항철도/2호선) 또는 망원역 — 대형 환승역, 랜드마크 명확 |
| **쿠킹 공간(시범)** | 연남/망원 **시간제 쿠킹 공유주방**(스페이스클라우드 등, 회당 5~8만원 예상) → CAPEX 0 |
| **쿠킹 공간(정착)** | **망원시장 안/인근 상설공간 or 로컬 식당 유휴시간 제휴**(허가·상생, 07번 문서) |
| **식재료** | 망원시장 당일 조달(원가↓·상생·진정성) |
| **동선/안전** | 지하철 1회 이내, 도보 10분 이내, 사전 지도·사진 안내, 청년 서포터 픽업 지원 |

## 6. 이동 리스크 점검 (외국인 관점)
- ✅ 공항→홍대입구 직통(환승 0), ✅ 3개 노선 환승 대형역, ✅ 영문 안내·구글맵 정확, ✅ 관광객 익숙한 지역이라 야간·주말 안전, ✅ 집결 랜드마크(연트럴파크) 명확.
- ⚠️ 주말 홍대 혼잡 → 집결 시간·장소 명확화, 청년 서포터 현장 안내로 해소.

## 7. 발표 포인트
> **"우리 쿠킹클래스는 인천공항에서 지하철 한 번(직통 53분)이면 닿는 연남·망원에서 엽니다. 빌릴 수 있는 쿠킹 공유주방이 실제로 풍부하고, 재료는 외국인도 찾는 망원시장에서 당일 조달합니다 — 접근성·공간·진정성이 한 동네에 다 있습니다."**
