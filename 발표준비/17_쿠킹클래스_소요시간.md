# 쿠킹클래스 소요시간 — 벤치마크 & 결정 (장보기 제외)

> 논점: "할머니 집 3시간 쿠킹클래스는 길다" → 순수 요리+식사 기준 평균은? 우리는 몇 시간으로?
> ## 결론: **표준 2시간 / 프리미엄 2.5시간.** 3시간은(시장투어 제외 시) 길다 → 단축 권장.

## 1. 평균 소요시간 (실측)
| 기준 | 시간 |
|---|---|
| 국제 핸즈온 쿠킹클래스 표준 | **2~3시간** (기초 1~2h, 복잡 3h+, 4~5h는 고난도) |
| 한식 원데이(마이리얼트립) | **2시간 30분** (조리+함께 식사) |
| 파스타 원데이 등 | 2시간 |
| 미국 홈쿠킹클래스(조리+풀밥상) | 약 3시간(조리·식사 반반) |
→ **표준 2~2.5시간.** 3시간은 '풀 밥상 포함 상단'. **시장투어 뺀 순수 클래스로는 긴 편.**

## 2. 우리 상황에서 3시간이 긴 이유
1. **시니어 체력** — 60대+에게 3h 연속은 부담(리스크·공간 문서의 반복 이슈). 2~2.5h가 지속가능.
2. **시장투어 분리** — 장보기 시간이 빠졌으니 3h를 채울 이유 없음.
3. **비용↓** — 3h→2h면 공유주방 회당 임대 75,000→약 50,000원 → **마진 개선**.
4. **회전율↑·게스트 부담↓** — 오전/오후 2회 가능, 여행자 일정도 수월.

## 3. 권장 구성 — 2시간 표준
| 시간 | 활동 |
|---|---|
| 10분 | 환영·앞치마·인사 |
| 10분 | 오늘 요리 소개 + 이모의 이야기 |
| 50분 | 조리 실습(손질 포함) |
| 5분 | 상차림 |
| **30분** | **함께 식사 + 밥상머리 이야기** (감성 핵심, 사수) |
| 15분 | 레시피카드·사진·마무리 |
| = 120분 | |

- **원칙:** 줄이는 건 조리 실습(1~2가지 집중)이지, **함께 먹으며 이야기하는 30분은 유지**(상품의 심장).
- **2.5시간 프리미엄**: 2~3요리 + 넉넉한 밥상 원하는 손님용 별도 상품.

## 4. 단가 영향(참고)
- 시간 단축은 단가를 낮출 이유가 되지 않음 — 가치(진정성·식사·레시피카드)는 동일. 단가 65,000원 유지.
- 오히려 임대비↓·회전율↑로 **회당 마진과 일일 매출이 개선**됨.
