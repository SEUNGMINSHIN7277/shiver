# 시장 장보기 투어 추가 시 — 새로 드는 비용

> 변경: 홈 쿠킹클래스 앞에 **인근시장(망원·광장 등) 장보기 투어**를 붙임.
> 흐름: 시장(음식·식재료 설명 → 간식 시식[가이드가 사서 나눠줌] → 장보기 미션 → 자유시간) → 할머니집 → 클래스 → 식사·전통주 → 정리·사진·마무리상품.
> ## 결론
> **추가 비용 ≈ 회당 5만원**(간식 시식 + 대학생 추가수당 중심), 월 24회 시 **+약 120만원**. 초기 1회성 ≈ 10만원.
> **단, 시장투어가 단가를 올려줘(콤보 프리미엄) 추가비용 이상으로 상쇄 → 마진에는 오히려 +.**

---

## 1. 새로 드는 비용 (기존 대비 '증분'만)
| 항목 | 회당 추가비용 | 설명 |
|---|--:|---|
| **간식 시식비**(가이드가 사서 나눠주기) | **~30,000** | 시장 먹거리(빈대떡·호떡·떡·마약김밥 등) 7인 시식 세트 |
| **대학생 가이드 추가수당** | **+15,000** | 시간 증가(쿠킹만 3h → 투어 1.5h 추가 = 약 4.5h). 수당 40,000→약 55,000 (18번 문서 통역시세 2~3h=4~5만 기준) |
| **보험 확장**(야외·이동) | ~1,500 | 시장·도보 구간 배상 커버(연 보험 소폭↑ 환산) |
| **교통비**(시장→집) | 0~5,000 | **근거리(망원시장↔망원동)면 0**, 원거리면 발생 → 시장·집 근접이 전제 |
| **소품 상각**(장바구니·미션카드) | ~2,000 | 아래 초기비용 상각 |
| **합계(근거리 기준)** | **≈ 48,000~53,000** | **약 5만원/회** |

- ※ **식재료비는 추가 아님** — '장보기 미션'에서 사는 게 곧 요리 재료(기존 8,000~15,000원/인). 위치만 시장으로 이동.

## 2. 초기 1회성 비용
| 항목 | 금액 |
|---|--:|
| 참가자 장바구니·에코백(8개, **브랜드 굿즈 겸용**) | ~40,000 |
| 다국어 시장 지도·미션카드·상점 안내물 인쇄 | ~30,000 |
| 가이드 시장 코스 교육(내부 진행) | 인건비(별도 아님) |
| **합계** | **~70,000~100,000원** |

## 3. 월 환산 & 상쇄
- 증분 비용: 5만원 × 24회 = **월 +120만원**.
- **상쇄:** 시장투어 결합(콤보)은 단가를 **인당 +15,000~30,000원** 올릴 수 있음(23번 문서 '수평 확장'). 7인 기준 **회당 +105,000~210,000원 매출** vs 추가비용 5만원 → **순마진 +.**
- → **투어 추가는 비용이 늘어도 단가·매출이 더 크게 늘어 마진에 유리.**

## 4. 비용 외 반드시 챙길 것 (돈은 아니지만 리스크)
1. **전통주 페어링은 여전히 규제** — 집에서 술 제공/판매 불가(21번 문서). BYO·전통음료·'막걸리 빚기 체험'으로 우회.
2. **관광가이드 자격 리스크 ↑** — 유상 시장 '투어'는 관광통역안내사 영역과 닿음. **'관광안내'가 아닌 '체험 프로그램(장보기 미션)'으로 설계** 유지 + 체험 호스트 프레임.
3. **시장 ↔ 할머니집 근접 필수** — 도보 10~15분 이내라야 교통비·동선·안전 OK. **입지 선정의 제약**(망원시장+망원동 / 광장시장+종로 단독주택).
4. **시간·체력·회전율** — 총 체험이 2h → 3.5~4h로 증가. 하루 2회(11~13/17~19)가 빠듯해짐, 시니어·가이드 체력↑. 정원·회차 재검토.
5. **진정성 설계** — 투어를 '가이드가' 진행하면 실무적이나, 우리 브랜드 핵심인 **'40년 단골 이모가 데려가는 시장'** 맛은 약해짐. (이모 동행은 진정성↑이나 체력·시간 부담) → 선택.

## 5. 발표 관점
- "시장투어를 붙이면 회당 약 5만원(간식·가이드)이 추가되지만, 단가를 15,000~30,000원/인 올릴 수 있어 **마진은 오히려 개선**됩니다."
- 단, **전통주·가이드자격·시장-집 근접**은 반드시 설계로 해결.
