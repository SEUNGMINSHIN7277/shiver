# 서울 이모삼촌 — 서비스 설계·구체화 (2대 축)

> 서비스의 스파인 = **음식**. 두 축으로 정리:
> **ⓐ 쿠킹클래스(만들기)** + **ⓑ 시장투어(맛보고 배우기)**.
> '골목·인생 이야기'는 별도 상품이 아니라 **두 체험에 흐르는 스토리텔링 레이어**.
> 원 제안서의 상품 3종(①시장동행+집밥 ②인생이야기투어 ③할머니집밥)을 이 2축 체계로 재정리.

---

## 0. 서비스 아키텍처 한눈에

```
        ┌─────────────────────────────────────────────┐
        │            서울 이모삼촌 (브랜드)              │
        └─────────────────────────────────────────────┘
                 │                          │
        ⓐ 쿠킹클래스 (만들기)      ⓑ 시장투어 (맛보고 배우기)
        "이모의 부엌에서            "이모의 단골 시장에서
         손맛을 배우고 함께 먹기"     먹거리·시장문화를 맛보며 걷기"
                 │                          │
                 └──────────┬───────────────┘
                            ▼
              ⓒ 플래그십 콤보 (ⓑ→ⓐ 결합)
        "시장에서 이모와 장보고 → 그 재료로 집밥까지"
                            │
                            ▼
                  ⓓ B2B 단체 버전 (팀빌딩·외국인 임직원)
```

**핵심 설계 원칙:** 두 축은 **독립 상품이자, 레고 블록**이다. 따로 팔고(짧게·싸게), 붙여 팔고(길게·프리미엄·플래그십), 단체로 키운다(B2B). → 고객의 시간·예산·관심에 맞춘 **가격·시간 사다리**가 자연히 생김.

| 상품 | 시간 | 정원 | 제안 단가 | 주 타깃 |
|---|---|---|---|---|
| ⓑ 시장투어 | 1.5~2h | 4~8명 | 45,000원 | 외국인·내국인, 입문·가벼움 |
| ⓐ 쿠킹클래스 | 2~2.5h | 4~6명 | 55,000~65,000원 | 외국인·내국인 2030 |
| ⓒ 콤보(플래그십) | 3.5h | 4~6명 | 75,000~85,000원 | 외국인(깊은 체험 원함) |
| ⓓ B2B 단체 | 협의 | 10~20명 | 800,000원~/회 | 기업·기관 |

> ※ 원 제안서는 콤보를 65,000원으로 잡았는데, 시장투어(45k)+쿠킹클래스(55k)의 결합가치를 보면 **콤보는 75~85k가 적정**(단품 합보다 저렴해 '묶음 이득'은 유지). 초기엔 65k 인트로 프로모션도 가능. → **가격은 결정 포인트(§8)**.

## 1. 전체 고객 여정 (발견 → 예약 → 체험 → 이후)

| 단계 | 무슨 일이 일어나나 | 담당 |
|---|---|---|
| **① 발견** | 글로벌 체험 플랫폼(에어비앤비 체험·마이리얼트립) 검색 노출, 게스트하우스 컨시어지 추천, 지역 SNS·유튜브 숏폼 | 청년(콘텐츠) |
| **② 예약·결제** | 플랫폼/자체 폼으로 예약, 인원·날짜·언어·식이제한 접수 | 청년 서포터 |
| **③ 체험 전** | 자동 리마인더 + **알레르기·비건/할랄 사전 확인**, 집결 위치 안내(지도·사진) | 청년 서포터 |
| **④ 체험 당일** | ⓐ/ⓑ/ⓒ 진행 (아래 §2·§3·§4) | 이모(진행) + 청년(운영·통역·촬영) |
| **⑤ 체험 후** | **다국어 레시피 카드/시장 지도 선물**, 단체사진 전송, 플랫폼 리뷰 요청, 재방문(다른 계절/메뉴) 안내, 체험 사진·영상은 마케팅 자산화 | 청년 서포터 |

> **재방문 설계:** "계절마다 메뉴·시장이 바뀐다" + "이모별 시그니처가 다르다" → 한 번 온 손님이 **다른 계절·다른 이모**로 재방문. 후기·콘텐츠가 쌓이며 플랫폼 랭킹↑(플라이휠).

## 2. ⓐ 쿠킹클래스 — 완전 설계

### 2-1. 표준 흐름 (2시간 30분 기준)
| 시간 | 활동 | 핵심 |
|---|---|---|
| 0:00 | 환영·앞치마·손씻기·자기소개 | 친척집에 온 분위기 |
| 0:10 | **오늘의 요리 소개 + 이모의 이야기** (이 음식에 얽힌 추억) | 요리에 스토리를 입힘 |
| 0:25 | 재료 손질 함께 | 손으로 참여 시작 |
| 0:50 | **조리 실습** — 이모 시범 → 참가자 따라하기 | 체험의 핵심 |
| 1:45 | 상차림·플레이팅 | 완성의 성취감 |
| 1:55 | **함께 식사 + 이야기 + Q&A** | *진짜 상품: 밥상머리 대화* |
| 2:20 | **다국어 레시피 카드 선물** + 단체사진 | 집에 가져갈 기억·재현 |

### 2-2. 메뉴 아키텍처 (한 클래스 = 메인 1 + 반찬 1~2 + 밥/국)
- **시그니처 (이모별 대표작):** 각 호스트가 가장 자신 있는 요리 1종을 간판으로 (개인화 = 진정성).
- **외국인 인기 표준:** 불고기 · 잡채 · 비빔밥 · 김밥 · **겉절이 김치**(즉석·발효대기 없음, 클래스 최적) · 김치전/파전 · 떡볶이.
- **집밥 정서(내국인 2030):** 된장/김치찌개 · 계절 나물 무침 · 제육볶음 · 계란말이.
- **계절 스페셜:** 봄(봄나물·화전) / 여름(콩국수·오이소박이·삼계탕) / 가을(송편·모둠전) / 겨울(만두·김장김치·팥죽).
- **식이 옵션(인바운드 필수):** **비건/베지테리언**(젓갈 뺀 김치·나물비빔밥·채소전), **할랄**(돼지·맛술 배제), 글루텐프리 대응.

> 조합 예시: "겉절이 + 불고기 + 밥"(입문) / "잡채 + 계절나물 + 밥"(대표) / "김치전·파전 + 막걸리"(저녁·캐주얼) / "만두 빚기"(겨울·가족).

### 2-3. 등급·변형
- **기본**(메인1+반찬1) / **프리미엄**(메인+반찬2+김치) / **시즌 스페셜**(명절 음식) / **가족·키즈**(쉬운 김밥·만두).

### 2-4. 역할 분담 (2인 1팀)
- **시니어 이모:** 시범·손맛·이야기·환대 (잘하는 것에만 집중)
- **청년 서포터:** 통역·결제·촬영·시간관리·안전·알레르기 확인·설거지 지원

### 2-5. '손맛'의 표준화 — 이 서비스의 진짜 엔지니어링
- 문제: "적당히·한 줌·감으로"는 **가르칠 수 없고 재현 불가**.
- 해법:
  1. **계량화 레시피 카드**: 이모의 "한 줌"을 그램·스푼으로 번역 (예: 소금 한 줌 ≈ 8g).
  2. **다국어화**(영·중·일) — Claude Code 세션이 초벌 번역·계량 변환을 도울 수 있음(비용 0).
  3. **조리 과정 영상 아카이브** — 교육 자료 + 마케팅 콘텐츠 겸용.
  4. 뼈대는 표준화하되 이모의 **'감·팁·스토리'는 살려** 진정성 유지.
- → 이것이 "복제 불가한 원본을 재현 가능한 시스템으로" 바꾸는 실제 실행.

### 2-6. 장소 — 집 vs 공유주방 (트레이드오프)
| | 이모의 집 부엌 | 시장 인근 공유주방 |
|---|---|---|
| 진정성 | 최고 | 중 |
| 위생·안전·법적 안정 | 낮음(회색지대) | 높음 |
| 규모(단체) | 어려움 | 가능 |
| 비용 | 0 | 임대비 |
- **추천:** **하이브리드** — 소규모·개인은 집(진정성), 단체·B2B는 공유주방. 또는 **시장 인근 공유주방을 "이모의 부엌"으로 브랜딩**해 진정성과 안정성 절충. → **결정 포인트(§8)**.

### 2-7. 차별화
진짜 가정 부엌 · 이모 본인의 시그니처 · 밥상머리 인생 이야기 · 시장에서 산 그날의 재료 → **"학원식 쿠킹클래스"와 완전히 다른 층위**.

## 3. ⓑ 시장투어 — 완전 설계

### 3-1. 표준 흐름 (2시간 기준, 단골 상점 5곳 큐레이션)
| 시간 | 스톱 | 무엇을 |
|---|---|---|
| 0:00 | 집결·시장 개요·역사 | 이 시장이 어떤 곳인지 |
| 0:10 | **Stop1 반찬가게** | 한국 반찬 문화 + 시식 (이모 단골, 덤·인사) |
| 0:25 | **Stop2 떡집·방앗간** | 떡·전통 간식 문화 + 시식 |
| 0:40 | **Stop3 먹거리 노포** | 빈대떡·전·순대·김밥 등 대표 먹거리 시식 |
| 1:05 | **Stop4 정육·건어물·나물** | 제철 식재료·손질법 이야기 |
| 1:20 | **Stop5 분식·주전부리** | 호떡·꽈배기·어묵 등 |
| 1:35 | 마무리: 노포에서 국밥/차 한잔 + 정리·질문 | 앉아서 마무리 대화 |

### 3-2. 시장별 캐릭터 (첫 타깃 선정용)
| 시장 | 성격 | 장단 |
|---|---|---|
| **광장시장**(종로) | 먹거리 성지(빈대떡·마약김밥·육회) | 인지도·인프라 최고 / 이미 관광화·혼잡 |
| **통인시장**(서촌) | 엽전 도시락·아기자기 | 체험 친화 / 규모 작음 |
| **망원시장**(마포) | 젊고 로컬·현지인 | **진정성 높음·덜 관광화** / 인지도 낮음 |
| **경동시장**(제기동) | 약령·나물·건어물, 경동1960 | 스케일·시니어 친화 / 거대·다소 산만 |
| **동네시장**(수유·정릉·영천 등) | 진짜 생활 시장 | 진정성 최고 / 먹거리 인프라 편차 |
- **전략적 관점:** 진정성(망원·통인·동네) vs 인프라·인지도(광장·남대문)의 트레이드오프. **이모의 실제 40년 단골 시장**이 어디냐가 1순위 기준. → **결정 포인트(§8)**.

### 3-3. 등급·변형
- **기본 미식투어**(시식 중심) / **스토리투어**(역사·문화 중심) / **테마투어**(김치로드·전로드·떡로드) / **장보기 미션**(→ ⓒ 콤보로 연결) / **야시장·저녁 버전**.

### 3-4. 역할 분담
- **시니어 이모:** 안내·시장 이야기·상인 소개·시식 큐레이션
- **청년 서포터:** 통역·시식비 정산·사진·동선·시간·안전

### 3-5. 시장 지식의 표준화
- **상점 스토리 카드**: 각 스톱의 소개 스크립트(유래·추천 먹거리·시식 포인트)를 다국어로.
- **시장 지도 선물**(다국어): 손님이 나중에 혼자 다시 올 수 있게 = 재방문·입소문.

### 3-6. 차별화
**40년 단골이 데려가는 시장** — 상인들이 반겨주고 덤·시식이 자연스러움. 일반 상업 가이드는 절대 못 만드는 '관계의 안내'.

## 4. ⓒ 플래그십 콤보 — 두 축의 결합 (3.5h)
```
[시장투어 축소판 1:20] 이모와 시장 돌며 오늘 요리할 재료 장보기(+시식)
        │  (도보 이동)
        ▼
[쿠킹클래스 2:00] 산 재료로 이모의 부엌에서 요리 → 함께 식사·이야기
        │
        ▼
[마무리 0:10] 다국어 레시피 카드 + 시장 지도 선물 + 단체사진
```
- 이게 원 제안서의 간판 상품(①). **"시장→부엌"의 완결된 하루** = 외국인이 가장 원하는 깊은 로컬 체험.
- 스토리 아크: *낯선 시장 → 이모와 장보기 → 함께 요리 → 밥상머리 대화 → 한국 가족이 생김.*

## 5. 계절성 = 버그가 아니라 기능 (재방문 엔진)
| 계절 | 쿠킹 메뉴 | 시장 볼거리 |
|---|---|---|
| 봄 | 봄나물 무침·화전 | 냉이·달래·딸기 |
| 여름 | 콩국수·오이소박이·삼계탕 | 제철 과일·복날 |
| 가을 | 송편·모둠전·게장 | 수확·전어·대하 |
| 겨울 | 만두·김장김치·팥죽 | 붕어빵·호떡·곶감 |
> "계절마다 다른 이모삼촌" → 시즌 마케팅 + 재방문 유인 + 콘텐츠 소재 무한.

---

## 6. 표준화 ↔ 진정성 균형 (설계 철학)
- **표준화해야 하는 것(재현성):** 안전·위생·시간·결제·통역·레시피 뼈대·상점 스크립트·알레르기 프로토콜.
- **표준화하면 안 되는 것(진정성):** 이모의 손맛·감·인생 이야기·상인과의 관계·그날의 즉흥.
- **원칙:** *운영은 시스템으로, 콘텐츠는 사람으로.* 이 경계가 곧 서비스 품질의 핵심.

---

## 7. 이 설계로 강해진 발표 메시지
- "우리 서비스는 **만들기(ⓐ)와 맛보기(ⓑ)** 두 축이고, 둘을 붙이면 **시장에서 부엌까지 완결된 하루(ⓒ)**가 됩니다."
- "**운영은 청년 서포터가 시스템으로, 콘텐츠는 이모가 사람으로** — 그래서 시니어는 잘하는 것(손맛·이야기)에만 집중합니다."
- "계절마다 메뉴와 시장이 바뀌어 **한 번 온 손님이 다시 옵니다.**"

---

## 8. 대표님이 정해야 할 설계 결정 포인트
1. **쿠킹클래스 장소**: 이모 집 / 공유주방 / 하이브리드 — 진정성 vs 위생·규모.
2. **첫 타깃 시장**: 진정성형(망원·통인·동네) vs 인프라형(광장·남대문) — 이모의 실제 단골이 최우선.
