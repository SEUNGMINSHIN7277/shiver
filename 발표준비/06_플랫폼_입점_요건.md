# 서울 이모삼촌 — 플랫폼 입점 가능성·요건 (에어비앤비 / 트립닷컴)

> 질문: 공유주방 + 할머님(호스트)을 확보했다고 할 때, 이 패키지를 트립닷컴·에어비앤비에 올릴 수 있나?
> **결론: 에어비앤비 체험 = 올릴 수 있음(공유주방이 오히려 유리). 트립닷컴 = 바로는 어려움(사업 설립 180일 요건) → 초기엔 에어비앤비+마이리얼트립/클룩으로 시작, 트립닷컴은 6개월 후 또는 애그리게이터 경유.**
> ※ 플랫폼 정책은 자주 바뀜 — 확정 전 각 플랫폼 호스트/공급자 페이지에서 라이브 재확인 필요.

---

## 1. 에어비앤비 체험 (Airbnb Experiences) — ✅ 가능

2025년 체험 프로그램이 리론칭되어 요리·푸드투어 카테고리가 활발. 등록은 **4가지 요건**을 충족해야 함:

| 요건 | 내용 | 우리 상태 |
|---|---|---|
| ① 신분 인증 | 호스트 본인 인증 | 쉬움 |
| ② **전문성 입증** | 자격증 / 포트폴리오 / **입증 가능한 경력** 중 하나 | 할머님의 평생 요리·시장 경력 = 경력. **사진·영상 포트폴리오로 입증** 필요 |
| ③ **면허·보험·허가** | 활동에 필요한 현지 인허가 + 보험. 음식 체험은 **식품취급 허가·위생** 필수 | **공유주방(영업신고 시설) + 영업배상책임보험**으로 충족 |
| ④ **시범(trial) 예약 품질 검증** | 공개 전 시범 운영이 품질 기준 통과해야 함 | **파일럿 4회(8월)**가 이 역할 수행 가능 |

- 음식 체험 추가 규칙: 현지 식품취급 허가, 식품안전(PAHO 가이드) 준수, 알레르기·식이제한 사전 안내. 위반 시 리스팅 제거.
- 한국 관련: 에어비앤비는 국내 규제 준수를 요구하며, 음식·체험 호스트는 **유효한 면허·보험 증빙 제출**을 요구받을 수 있음. (2024.10부터 숙박은 영업신고증 의무화 — 체험도 인허가·보험 증빙 기조.)

**→ 핵심: 개인 '할머니 집'이 아니라 '공유주방'을 쓰면 ③(허가·위생)이 깔끔히 해결돼 오히려 입점이 쉬워진다.**

## 2. 트립닷컴 (Trip.com) — ⚠️ 조건부(초기엔 어려움)

- 트립닷컴은 **공급자(vendor/merchant) 등록 모델**(개인 P2P가 아님).
- **★설립 후 180일(약 6개월) 이상 된 사업체만 신청 가능** — 갓 시작한 팀은 **직접 입점 즉시 불가**.
- 1개 사업체 1계정, 계열·가족관계 중복 등록 금지.
- 우회로: **애그리게이터(예: Bókun)** 를 통해 트립닷컴에 유통 연결 가능. 또는 Viator·GetYourGuide 공급자로 등록하면 다채널 유통.

**→ 트립닷컴은 '6개월 운영 실적'을 쌓은 뒤(=시범사업 후) 또는 애그리게이터 경유가 현실적.**

## 3. 그래서 채널 전략 (초기 → 확장)

| 시기 | 채널 | 이유 |
|---|---|---|
| **초기(9월 유료개시)** | **에어비앤비 체험** + **마이리얼트립 / 클룩(Klook)** | 개인·소규모도 입점 쉬움, 한국 인바운드 강세. 서양·글로벌(에어비앤비) + 아시아(클룩) |
| 보조 | **크리에이트립(Creatrip)** | 중화권·아시아 여행자 특화 |
| **정착 후(6개월+)** | **트립닷컴** 직접 입점 / **Bókun 등 애그리게이터** | 180일 요건 충족 후, 중국·아시아 대형 유통 |
| 상시 | **게스트하우스 제휴 · 자체 예약** | 수수료 0, 마진 최상 |

> 원 제안서가 언급한 "글로벌 체험 플랫폼 2곳 입점"은 **에어비앤비 + 마이리얼트립(또는 클룩)** 조합이 현실적. 트립닷컴은 목표로 두되 후순위.

## 4. ★입점에 필요한 준비물 체크리스트 (그리고 우리 계획과의 일치)

| 준비물 | 필요 이유 | 현재 |
|---|---|---|
| **사업자등록** | 트립닷컴/전문 호스트 필수, 세금계산 | ⚠️ **미정 — 고용 주체 결정과 동일 이슈**(개인사업자 등) |
| **공유주방(영업신고 시설)** | 식품 허가·위생 = 플랫폼 요건 충족 | 확보 예정(대표님 전제) ✓ |
| **영업배상책임보험** | 플랫폼·안전 요건 | 예산에 편성됨 ✓ |
| **위생교육 이수** | 식품안전 준수 | 40h 교육에 포함 ✓ |
| **다국어 상품페이지·사진·영상** | 리스팅 콘텐츠·전문성 입증 | 파일럿 촬영·홍보물 예산 ✓ |
| **시범 예약 실적** | 에어비앤비 품질 검증 | 파일럿 4회(8월) ✓ |

**→ 발표 강점:** *"우리 파일럿 계획(8월 시범 4회·촬영·공유주방·위생교육·보험)은 사실상 플랫폼이 입점 심사에서 요구하는 것들을 그대로 만들어냅니다."* = 수요처(채널) 확보 경로가 이미 설계돼 있다는 강력한 증거.

## 5. 정직한 유의점
- 에어비앤비 체험은 **큐레이션형**이라 신청=승인 아님. 전문성·품질 심사 통과 필요(포트폴리오가 관건).
- '할머니'의 전문성 입증은 **자격증이 없으므로 사진·영상·후기 포트폴리오**로 대체 → 파일럿 촬영이 중요.
- 플랫폼 정책·수수료(대략 15~20%)는 수시 변동 → 확정 전 라이브 확인.
- 트립닷컴 180일 요건은 확인된 사실이나 국가별 예외·애그리게이터 경로는 별도 확인 권장.

## 6. 발표 한 줄
> **"공유주방과 보험·위생교육을 갖추면 에어비앤비·마이리얼트립 입점은 가능하고, 우리 8월 파일럿이 곧 입점 심사에 필요한 실적·콘텐츠를 만듭니다. 트립닷컴은 6개월 운영 후 확장합니다."**
