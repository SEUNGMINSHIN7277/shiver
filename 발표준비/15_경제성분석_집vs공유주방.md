# 경제성분석 — 할머니 집 vs 공유주방 (체계적 비교)

> 동일 원가모델 위에서 평균 추정가로 **단위경제성 → 월/연 손익 → 확장(6명) → 리스크 조정**까지 계층 분석.
> (재현 스크립트 `econ_compare.py`, 단가·원가 근거는 09·10번 문서)
> ## ⚖️ 핵심 결론 (역설)
> **① 회당·호스트 1인 관점: 집이 더 남는다** (회당 임대료 75,000원을 아끼므로).
> **② 프로그램(6명)·확장·리스크 관점: 공유주방이 이긴다** (집은 자격 단독주택 6채 확보가 비현실적).
> **③ 갈림 지점 = '집 셋업 성공확률'.** 이 확률이 **약 27%(프리미엄가)/49%(동일가)를 넘으면 집이 유리**, 못 넘으면 공유주방. 파일럿 현실 확률(~20%)에선 **공유주방 우위.**

---

## 0. 공통 가정 (평균 추정)
| 항목 | 값 |
|---|---|
| 수수료 / 식재료 / 서포터 / 소모품 / 호스트임금 | 15% / 9,000원·인 / 40,000원 / 8,000원 / 55,000원·회 |
| 월 간접비(호스트1) / 월 수업수 | 150,000원 / 15회 |
| **공유주방** | 단가 62,000 · 정원 5 · **회당 임대 75,000** · CAPEX 0 · 연보험 60만 |
| **집(동일단가)** | 단가 62,000 · 정원 4 · 임대 0 · **초기 CAPEX 150만**(소방·개조·등록) · 연보험 90만 |
| **집(프리미엄가)** | 단가 **75,000**(집 프리미엄 +21%) · 정원 4 · 임대 0 · CAPEX 150만 · 연보험 90만 |

## 1. 회당 단위경제성 (운영주체 마진)
| 시나리오 | 매출 | −수수료·식재료·서포터·공간·소모품·호스트 | **회당 마진** |
|---|--:|---|--:|
| 공유주방 | 310,000 | (위 항목 합) | **40,500** |
| 집(동일단가) | 248,000 | | **71,800** |
| 집(프리미엄가) | 300,000 | | **116,000** |
→ **집이 회당 우위.** 정원이 1명 적어도 **회당 임대료 75,000원 절약**이 이를 압도.

## 2·3. 월/연 손익 (호스트 1인, 상각·보험 포함)
| 시나리오 | 월 운영이익 | 연 운영이익(2년차~) |
|---|--:|--:|
| 공유주방 | 407,500 | 4,890,000 |
| 집(동일단가) | 789,500 | 10,224,000 |
| 집(프리미엄가) | **1,452,500** | **18,180,000** |
→ 호스트 1인 기준 **집이 2~3.6배 더 남음** (임대료 미부담 효과).

## 4. 확장 시나리오 — 프로그램 목표 6명
| 시나리오 | 6명 월이익 합 | 필요 인프라 |
|---|--:|---|
| 공유주방 | 2,445,000 | **공유주방 1~2곳 순환 (용이)** |
| 집(동일단가) | 4,737,000 | 자격 단독주택 **6채** + 등록 + 보험 (비현실) |
| 집(프리미엄가) | 8,715,000 | 자격 단독주택 **6채** + 등록 + 보험 (비현실) |
→ 집은 **숫자상 총이익이 크지만**, 6명이면 **자격 단독주택 6채·등록·보험·안전을 6배로** 갖춰야 함(14번 문서 리스크).

## 5. ★리스크(실현가능성) 조정 기대값
집은 호스트마다 [자격 단독주택 + 외도민/샌드박스 + 보험 인수 + 안전 + 의향]을 **모두** 갖춰야 성립 → 성립확률이 낮음.

| 시나리오 | 6명 월이익 | 성립확률 | **리스크조정 기대값** |
|---|--:|--:|--:|
| 공유주방 | 2,445,000 | 95% | **2,322,750** |
| 집(동일단가) | 4,737,000 | 20% | 947,400 |
| 집(프리미엄가) | 8,715,000 | 20% | 1,743,000 |
→ **리스크를 반영하면 공유주방이 역전.**

### ★ 갈림 지점(손익분기 확률)
- 집(프리미엄가)이 공유주방을 이기려면 **집 셋업 성공확률 > 26.6%**
- 집(동일단가)이 이기려면 **> 49.0%**
- **해석:** "자격 단독주택을 구해 합법·안전하게 셋업할 확률이 27%를 넘는다"고 보면 **집이 유리**, 아니면 **공유주방**. 파일럿 현실(아파트 거주 다수·법·보험·안전)에선 20% 안팎 → **공유주방 우위.** 단, 외도민·샌드박스 경로가 정착해 확률이 오르면 **집의 경제성이 역전**됨.

## 6. 민감도 (집 프리미엄가 기준, 월이익)
| | 단가 65k | 75k | 85k |
|---|--:|--:|--:|
| 정원 3명 | 248,750 | 631,250 | 1,013,750 |
| 정원 4명 | 942,500 | 1,452,500 | 1,962,500 |
| 정원 5명 | 1,636,250 | 2,273,750 | 2,911,250 |
→ 집 경제성은 **정원·단가에 매우 민감**. 정원 3명·65k면 급감(월 25만). 즉 집은 **작은 부엌(정원 제약)이 약점.**

## 7. 종합 판정 (객관)
| 관점 | 우위 | 이유 |
|---|---|---|
| 회당·호스트 1인 수익 | **집** | 회당 임대료 75,000원 미부담 + 프리미엄 |
| 초기비용·즉시성 | **공유주방** | 집은 CAPEX 150만/채 + 법·보험 셋업 시간 |
| 확장성(6→30명) | **공유주방(압도)** | 집은 자격주택 확보 비현실 |
| 리스크조정 기대값 | **공유주방** | 집 성립확률 낮음(~20% < 27%) |
| 상한 수익(성립 시) | **집** | 임대료 없어 마진 구조가 우월 |

## 8. 최종 권고
1. **시범·확장 코어 = 공유주방.** 리스크조정 기대값·확장성·즉시성에서 우위. 지원금 기간 내 실현 가능.
2. **집 = 고마진 프리미엄 단일 상품.** 임대료를 안 내 **회당·호스트 수익은 최고** → **특정 자격 호스트(단독주택·합법 셋업 가능)**가 나오면 **프리미엄 상품으로 운영할 경제적 이유가 충분.**
3. **전략적 함의:** 외도민·규제샌드박스로 **집 셋업 성공확률을 27% 위로 끌어올리면** 집이 경제적으로도 정답이 됨 → **성숙기 목표 = '집 셋업 경로 확립'.**
4. **발표 활용:** "공유주방으로 안전하게 시작하되, 집 모델은 회당 임대료를 없애 마진이 더 좋으므로 합법 경로(도시민박업·샌드박스)를 확보해 프리미엄으로 확장한다" = 경제성까지 계산된 단계적 로드맵.

### 가정 조정
성립확률·정원·단가·임대료·CAPEX·보험 등 **모든 변수 조정 후 재계산 가능**. (예: 집 정원을 6명으로 보거나, 공유주방 임대료를 시장/식당 제휴로 40,000원으로 낮추면 결과가 달라짐.)
