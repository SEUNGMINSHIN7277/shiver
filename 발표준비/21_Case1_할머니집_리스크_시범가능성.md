# Case 1 (할머니 집 쿠킹클래스) — 필수 해결 리스크 & 시범 가능성

> Case 1 원안 검토: 6개 프리미엄 입지 할머니 집, 전통주 페어링 포함, 단가 134,900원, 하루 2회·주3회.
> ## 결론 요약
> - **반드시 해결(deal-breaker) TOP 3: ① 전통주 페어링(주류 규제) ② 주거형태(단독주택 vs 아파트) ③ 합법 영업 프레임(식품+관광).**
> - **시범사업: Case 1 원안 그대로는 기간(7~10월) 내 불가. '최소 합법 버전'(1~2 단독주택·전통주 제외·외도민 등록)으로 축소하면 조건부 가능.**

## 0. 숫자 검증 (Case 1)
| 항목 | 계산 | 결과 |
|---|---|---|
| 시니어 월급 | 45,000 × 24회 | 108만원 ✓ |
| 대학생 | 40,000 × 24회 | 96만원 ✓ |
| 인건비 | 108+96 | 204만원 ✓ |
| 식재료 | 15,000 × 7 × 24 | **252만원** ✓ (원문 '25,220,000'은 오타 → 2,520,000) |

| **누락 비용** | | ⚠️ **플랫폼 수수료(15~20%≈240~320만)·전통주/마무리상품 원가·보험료·마케팅 미반영** |
- 반영 시에도 프리미엄 단가(134,900) 덕에 마진은 큼 → **단, 134,900원(≈$100) 수요 검증 필요**(시장 표준가 5~9만의 2배, 프리미엄 포지션).

## 1. ★반드시 해결해야 하는 리스크 (Deal-breaker)

### 🔴 #1 전통주 페어링 = 주류 규제 (Case 1 최대 신규 블로커)
- **집에서 술을 팔거나 제공 = 무면허 주류 판매.** 주류 판매는 **일반음식점 영업신고 + 의제주류면허**가 있어야 가능한데, **주택은 일반음식점 시설기준(정화조·소방·용도)을 못 맞춰 라이선스 불가.**
- **'시음' 제공조차 제조자·수입업자만** 정해진 조건에서 가능 → 우리는 불가. 무상이든 유상이든 주세법 적용, 위반 시 과태료·영업정지·형사고발.
- **해결(必):** 전통주를 **유료 상품에서 제외** / **손님 BYO(직접 지참·본인 음용)** / **전통음료(식혜·수정과) 페어링으로 대체** / (장기) 라이선스 매장·제조사 연계. → **원안 '페어링 제공'은 그대로 못 감.**

### 🔴 #2 주거 형태 — 단독주택 vs 아파트
- **강남·명동·홍대·성수·용산·종로에서 60대 여성의 자가 단독주택 = 매우 드묾**(대부분 아파트·고가). **아파트면 공동주택 주거용도 위반**(영리 상업이용 제약 + 이웃 민원).
- **해결(必):** **단독주택 확보**(예: 종로 한옥, 서촌·성북 단독) 또는 아파트 관리규약 허용·동의 확인. 6개 입지 전부 프리미엄이라 단독주택 확보 난도 높음.

### 🔴 #3 합법 영업 프레임 (식품위생 + 관광)
- 집에서 유료 음식 제공 = 무신고 영업 회색지대(순수 '교육'은 합법이나 '식사 제공' 비중 큼).
- **해결(必):** **'교육·체험(공동조리)' 설계** + **외국인관광 도시민박업 등록**(외국인 대상 가정문화체험·식사 제공을 합법화하는 실재 제도, 2주·수수료 2만) 또는 규제샌드박스. **관할 구청·보건소 서면질의로 확정.**

### 🟠 #4 고용 주체 / 사업자등록
- 시니어에게 월급 108만 + 4대보험 지급 = **'고용'**. 집은 시니어 소유인데 **고용주(사업자)는 누구인가?**
- **해결(必):** **운영주체 사업자등록** + 시니어를 **근로자로 고용**(집은 '장소 제공') 구조 확정.

### 🟠 #5 보험 (식중독·배상·상해)
- 무신고 가정영업은 보험 인수 어려움. 식중독 배상 판례·상해 리스크 실재.
- **해결(必):** 음식물배상책임·영업배상 **인수 가능 여부 보험사 확인** + 플랫폼 ELI 보완.

### 🟠 #6 안전 (시니어·게스트)
- 낯선 외국인이 **하루 2회** 시니어 여성 집 방문. 대학생 동행이 완충하나 필수.
- **해결(必):** 게스트 신원확인(플랫폼)·대학생 상주·안전 프로토콜.

> **정리:** #1~#3은 **안 풀리면 사업이 위법**이라 절대 필수. #4~#6은 노력으로 해결 가능하나 반드시 세팅.

## 2. 시범사업, 굴릴 수 있는가?

### ❌ Case 1 원안 그대로 = 파일럿 기간(7~10월) 내 불가
- 전통주 규제(라이선스 불가) + 6개 프리미엄 입지 단독주택 확보 + 샌드박스(수개월) = **기간 내 동시 충족 불가능.**

### ✅ '최소 합법 파일럿'으로 축소하면 = 조건부 가능
| 요소 | 최소 합법 버전 |
|---|---|
| 주택 | **1~2개 단독주택**(종로 한옥/서촌·성북 단독 등), 외도민 등록 가능한 곳 |
| 대상 | **외국인 중심**(외도민은 외국인 전용) — 내국인은 공유주방으로 분리 |
| 전통주 | **유료 제외** → 전통음료 페어링 or 손님 BYO |
| 합법틀 | '교육·체험' 설계 + **외도민 등록(2주)** + 구청·보건소 서면질의 |
| 보험 | 음식물배상·영업배상 가입 확인 |
| 인력 | 대학생 동행(안전·통역), 사업자등록 + 시니어 근로계약 |
| 규모 | 하루 1~2회 × 1~2 하우스, 4~8주 파일럿 |
→ 이 정도면 **8~10월에 소규모 검증 가능.** 단 준비(등록·보험·서면질의)에 3~4주.

### 판단
- **할머니 집 = "고마진 프리미엄" 검증용 소규모 파일럿은 가능**(경제성분석 15번: 집은 임대료 0 + 프리미엄가라 마진 최고, 단 성립확률이 관건).
- **그러나 시범사업의 '메인 엔진'으로는 리스크 과다** → **메인은 공유주방(Case 2), 할머니 집은 1~2곳 프리미엄 파일럿 병행**이 현실적.

## 3. 발표 관점
- Case 1의 강점(프리미엄 단가·고마진·진정성)은 인정하되, **"전통주·주거·합법틀 3대 리스크를 인지하고, 외도민 등록·전통음료 대체·단독주택 선별로 최소 합법 파일럿을 설계했다"**고 제시하면 **리스크 관리 역량**으로 가점.
- **정직 포인트:** "6개 프리미엄 입지 전면 전개는 성숙기 목표, 시범은 1~2 하우스"로 단계 구분.
