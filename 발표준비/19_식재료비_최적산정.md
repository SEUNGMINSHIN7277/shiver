# 클래스당 식재료비 최적 산정

> 질문: 한 클래스당 식재료비를 얼마로? → **1인 8,000~9,000원(넉넉히), 회당(5인) 약 40,000~45,000원.**
> 핵심: 체험상품은 원가율이 낮아 **넉넉해도 부담이 적다** → '아끼기'보다 **'메뉴 선택·제철·시장조달로 최적화'**가 정답.

## 1. 두 렌즈로 본 적정선

### (A) 바텀업 — 실제 메뉴 원가 (1인, 시장조달·집밥 기준)
| 메뉴 유형 | 1인 재료비(추정) |
|---|---|
| 야채·발효 중심 집밥(전·나물·김치·비빔밥) | 4,500~6,000원 |
| 표준(잡채/제육 + 반찬 + 밥) | 6,000~8,000원 |
| 고기·해물 넉넉(불고기·해물전) | 8,000~11,000원 |
→ 우리 '이모 집밥'(1메인+1~2반찬+밥, 함께 식사)은 **6,000~9,000원/인** 범위.

### (B) 톱다운 — 원가율(food cost ratio)
- 외식업 표준 원가율: **일반 음식점 30~40%**, 카페·디저트 20~30%, 고급 40~50%.
- **그러나 우리는 '식당'이 아니라 '체험'** — 가격의 대부분이 교육·경험·인건비. 식재료는 일부.
- 단가 65,000원 대비 식재료 원가율:
  | 1인 식재료 | 원가율(정원5) |
  |---|---|
  | 6,000 | 9.2% |
  | **8,000** | **12.3%** |
  | 9,000 | 13.8% |
  | 10,000 | 15.4% |
- → **9,000원을 써도 원가율 14%** = 음식점 표준(30~40%)의 **절반 이하.** **넉넉해도 마진 부담이 작다.**

## 2. ★ 결론 — '아끼기'가 아니라 '넉넉하게, 대신 똑똑하게'
- **최적: 1인 8,000~9,000원 (회당 40,000~45,000원, 정원 5인 기준).**
- 이유: 체험상품 원가율이 낮으니, **식재료를 조금 아껴 500~1,000원 남기는 것보다, 넉넉한 밥상으로 후기 평점을 올리는 게 훨씬 이득**(후기→플랫폼 랭킹→예약 = 플라이휠). *'이모 집밥은 푸짐하다'*가 브랜드.
- **너무 낮추지 말 것:** 1인 5,000원 이하면 밥상이 빈약해 보여 후기 리스크 → 아낀 돈보다 손해.

## 3. 진짜 최적화 지렛대 = 원가율 낮추기가 아니라 3가지
1. **메뉴 선택** — 진정성·가성비 높은 요리(전·잡채·김치·나물·비빔밥·떡볶이)로 구성. **비싼 단백질(한우·갈비)은 지양.** 집밥은 원래 야채·발효 중심이라 진정성과 저원가가 동시에 성립.
2. **시장·제철 조달** — 전통시장은 마트보다 저렴 + **제철 재료는 싸고 신선하고 진정성↑**(계절 메뉴 = 브랜드 자산). 상인 상생 덤·시식도.
3. **묶음 구매** — 4~6인분 한 번에 사면 단가↓.

## 4. 경제성 모델 반영
- 기존 모델 9,000원/인 = **최적 상단**에 위치(넉넉·안전). 유지해도 원가율 14%로 건전.
- 원한다면 **표준 8,000원**으로 잡아 소폭 마진 개선 가능(회당 5,000원↑) — 단, 밥상 풍성함은 유지.
- **권장 확정: 1인 8,000원(표준)·9,000원(넉넉/고기메뉴), 회당 40,000~45,000원.**

## 5. 실전 — 7인분 장보기 예산 (챙겨갈 현금)
표준 8,000~9,000원/인 × 7 = **56,000~63,000원**. 시세변동·넉넉구매 버퍼 포함 **현금 60,000~65,000원 챙기면 충분.**

### 예시 A — 표준(고기 포함): 불고기 + 겉절이김치 + 나물 + 밥 (7인)
| 품목 | 금액 |
|---|--:|
| 불고기용 소고기 800g(시장) | ~18,000 |
| 야채(양파·대파·당근·표고) | ~6,000 |
| 불고기 양념(간장·설탕·마늘·배·참기름 배분) | ~5,000 |
| 겉절이(절임배추/얼갈이+고춧가루·마늘·액젓) | ~7,000 |
| 나물(콩나물·시금치+양념) | ~4,000 |
| 쌀 7인분 + 기타(기름·깨 소진분) | ~5,500 |
| **합계** | **~45,500원** (넉넉히 사면 ~55,000) |

### 예시 B — 알뜰(야채중심): 잡채 + 김치전 + 나물 + 밥 (7인)
| 품목 | 금액 |
|---|--:|
| 당면 500g + 잡채 야채 + 소고기 200g + 양념 | ~17,000 |
| 김치전(김치·부침가루·계란·오징어 조금) | ~7,000 |
| 나물 + 밥 + 기타 | ~10,000 |
| **합계** | **~34,000원** |

### 정리
| 메뉴 | 7인 식재료 | 1인 환산 |
|---|--:|--:|
| 알뜰(야채중심) | 34,000~45,000 | 5,000~6,400 |
| 표준(고기 포함) | 48,000~58,000 | 6,900~8,300 |
| 넉넉/프리미엄 | 60,000~70,000 | 8,600~10,000 |
→ **7인이면 현금 60,000~65,000원 챙기면 표준~넉넉 메뉴를 여유 있게 준비 가능**(남으면 다음 회차·시식용). 최소 40,000원이면 알뜰 야채중심 가능.
