# 보험료 & 플랫폼 수수료 — 원가 가정 (전 모델 공통)

> 목적: 경제성 모델에 넣을 **보험료·플랫폼 수수료**를 실제 요율로 확정.
> ## 결론
> - **보험: 연 50~70만원**(음식물배상+영업배상+상해 종합) → **회당 약 3,000원 / 월 약 5만원.** (저렴·필수)
> - **플랫폼 수수료: 파일럿 20% / 정착 blended 15%** (채널 믹스로 조절).

---

## 1. 보험료 — "어떻게 생각할까"

### 어떤 보험이 필요한가
| 보험 | 무엇 | 실제 연 보험료 |
|---|---|---|
| **음식물배상책임보험** | 식중독·이물질로 고객 피해 | **연 2.5만~10만원** (30평 음식점 2.5~4.9만, 60평 5~6만) |
| **영업배상/시설소유관리자배상** | 매장 내 고객 부상 | 연 10~30만 (규모별) |
| **여행자·행사·상해보험** | 게스트 안전사고 | 연/건별 |
| **Airbnb ELI(체험 배상보험)** | 게스트 신체·재산 피해 $100만 | **무료·자동**(플랫폼 예약분) |

### 핵심 판단
- **보험은 '싸고 필수'다.** 식중독 배상 판례가 실재(사망 배상 인정)라 반드시 필요하지만, **음식물배상책임은 연 몇만원**으로 저렴.
- **플랫폼(에어비앤비) 예약은 ELI가 $100만 무료 커버** → 게스트 상해 리스크 상당 부분 해결. 직판·비플랫폼분만 자체 보험으로.
- **종합(음식물배상+영업배상+상해)로 연 50~70만원**이면 충분(원 제안서 60만원과 일치).
- **회당 영향 미미:** 60만/년 ÷ 180회 ≈ **회당 3,300원**, 또는 **월 5만원**.
- ⚠️ **집(무신고 가정영업)은 보험 인수가 어렵거나 비쌈** → 합법 공간(공유주방/외도민 등록)이 보험에서도 유리.

### 모델 반영값: **연 60만원(월 5만원 / 회당 3,000원)**

---

## 2. 플랫폼 수수료 — "몇 %로 잡을까"

### 플랫폼별 실제 수수료율 (2025~2026)
| 플랫폼 | 수수료 | 비고 |
|---|---|---|
| **에어비앤비 체험** | **20%** | 호스트 요금, 정산 시 자동 공제 |
| **마이리얼트립** | **20%**(투어·클래스) / 10%(미식·입장권) | 쿠킹'클래스'는 20% 적용 가능 |
| **클룩(Klook)** | **15~25%** | 상품·지역별, 최저 15% |
| GetYourGuide | 20~30%(표준 30%, 협상 25~28%) | 서구권 |
| Viator | 20~30%(25% 흔함) + 상품등록비 $29 | |
| Trip.com | 약 10~20% | |
| **직판/게스트하우스/B2B** | **0%** | 수수료 없음 |
→ 관광·체험 OTA 일반 대역 **20~25%**, 우리 주력(에어비앤비·마리트)은 **20%**.

### 핵심 판단
- **수수료는 최대 단일 변동비** — 채널 믹스가 마진을 좌우.
- **파일럿 초기 = 플랫폼 의존(자체 고객 없음) → 20%로 보수적 산정.**
- **정착기 = 직판·게하 제휴·B2B·재방문 늘려 blended 15%(또는 그 이하)로 낮추는 게 마진 전략.**
- 모델 권장: **파일럿 20% / 정착 15%.** (이전 모델의 15%는 '정착·직판 확보' 전제 → 파일럿은 20%가 안전)

### 모델 반영값: **파일럿 20%, 정착 15%**

## 3. Case 1(할머니 집)에 반영한 월 손익 (5인·24회)
| 항목 | 금액 |
|---|--:|
| 매출 (134,900×5×24) | +16,188,000 |
| 플랫폼 수수료 20% | -3,237,600 |
| 인건비(시니어+대학생) | -2,040,000 |
| 식재료(15,000×7×24) | -2,520,000 |
| 보험(월) | -50,000 |
| **= 소계(전통주·마케팅·기타 전)** | **≈ +8,340,000** |
- 여전히 큰 흑자 — **프리미엄 단가(134,900) 덕**. 단 ①134,900원 수요 검증 ②전통주·마케팅·기타 원가 ③합법성(21번 문서)이 관건.
- 초기비용 50만/가구는 1회성(상각 월 ~2만).

## 4. 발표 활용
- "보험은 음식물배상 등 종합 연 60만원(회당 3천원)이면 충분하고, 플랫폼 예약은 에어비앤비 $100만 배상보험이 무료로 커버합니다."
- "수수료는 초기 20%로 보수적으로 잡되, 직판·게스트하우스·B2B·재방문을 늘려 15%로 낮추는 게 우리 마진 전략입니다."
