# 우리만의 차별점 — 게이미피케이션 & 시그니처 경험 (깊은 이데이션)

> 목표: 기존 쿠킹·시장 투어가 절대 못 하는 우리만의 재미·감동 차별점.
> ## 출발 철학
> 경쟁사는 **'2시간짜리 거래(요리 강습)'**를 판다. 우리는 **'평생 가는 관계(한국 가족)'**를 판다.
> 복제 불가의 핵심 자산 = ① 진짜 할머니 ② 그녀의 40년 단골 관계 ③ 사라지는 손맛 ④ 세대·국경을 잇는 관계.
> → 차별점은 전부 "**진짜 할머니가 있어야만 성립하는 것**"에서 나온다. 스튜디오 20대 셰프는 흉내낼 수 없다.

---

## 🏆 플래그십 — "한국 할머니가 생긴다" : 입양 · 계승 · 지속의 3막

경쟁사는 2시간 클래스를 판다. **우리는 평생 한국 할머니를 준다.**

### 1막 · 입양 (Adoption) — 클래스 시작
- 할머니가 각 손님에게 **한국 이름을 지어준다**(뜻과 함께). *"너는 오늘부터 우리 손주, 이름은 '복순이'."*
- **손주 번호** 부여 — *"너는 순자 할머니의 47번째 손주야."* 앞치마 이름표 + '손주 등록증'.

### 2막 · 계승 (Inheritance) — 요리
- 요리는 배우는 게 아니라 **물려받는 것.** 할머니가 자기 시그니처 레시피를 *"너에게 물려준다"*고 선언.
- 그 레시피는 **「이모삼촌 손맛 아카이브」**에 손님 이름과 함께 **할머니→손주 계보**로 등재. *(사라지는 할머니 손맛을 기록·보존하는 문화유산 프로젝트)*
- **'손맛 계승 증서'** 수여 — *"당신은 순자 할머니 김치 손맛을 물려받은 47번째 계승자입니다."*

### 3막 · 지속 (The bond that lasts) — ★진짜 무릎 탁
- **명절마다 할머니가 안부를 보낸다.** 설날·추석·손님 생일에 할머니(+청년 서포터 운영)가 짧은 개인 메시지:
  > *"우리 47번째 손주 '사라'야, 오늘 설날이야. 떡국 꼭 먹어야 나이 한 살 더 먹는 거 알지? — 순자 할머니가."*
- 일회성 관광 → **평생 관계.** *"한국에 진짜 할머니가 생겼다"*를 은유가 아니라 **실제로** 구현.
- 재방문·추천 시 손주 등급 상승(첫 방문 손주 → 효손 → 종손…).

### 왜 이게 무릎을 치게 하나
| 축 | 이유 |
|---|---|
| **감동** | "한국에 가족이 생긴다"를 진짜로 구현 — 눈물 버튼 |
| **복제 불가** | 진짜 할머니 + 진짜 관계가 있어야 성립. 스튜디오 셰프는 불가 |
| **비용 ≈ 0** | 이름 짓기·명절 메시지는 인건비만(청년 서포터 운영) |
| **바이럴** | "한국 할머니한테 입양됐어요" 릴스, 작별 포옹, 명절 메시지 인증 = 무한 콘텐츠 |
| **공공가치(공모 가점)** | 손맛 아카이브=문화유산 보존, 시니어 존엄, 세대·국경 교류 |
| **리텐션 엔진** | 명절 메시지 = 재방문·추천을 부르는 마케팅비 0 장치 |

## 🎮 단계별 게이미피케이션 (루트에 심는 재미)

### 🏪 시장 — "할머니 단골 흥정 배틀 & 정(情) 미션"
- 미션카드: 할머니가 알려준 한국말(*"깎아주세요!"*)로 상인과 흥정 → **덤 받아오기**.
- ★핵심: **40년 단골이라 상인들이 놀아준다** — 덤 주고, 농담하고, 반겨줌. 외국인이 **'정'과 '덤' 문화를 체험**. *낯선 관광객은 절대 못 받는 대접 = 복제 불가.*
- 할머니 단골집 5곳 **'정 스탬프북'** 도장.

### 🍳 쿠킹 — "손맛 시험" + "할머니 잔소리 빙고"
- **손맛 시험:** 할머니는 *"한 줌," "적당히"*로 요리. 손님이 따라 하면 **저울로 정답 공개 + 할머니 채점**(*"우리 손주 합격!"*). '손맛=계량 불가'를 게임으로.
- **★할머니 잔소리 빙고:** 한국 할머니 특유의 애정 잔소리 빙고판 — *"많이 먹어" · "왜 이렇게 말랐어" · "남기지 마" · "천천히 먹어" · "이거 몸에 좋아"*. 할머니가 말할 때마다 체크, 빙고면 상품.
  → 외국인이 **한국 할머니의 '정'을 웃으며 체험** = 폭소·바이럴 폭탄. (한국인은 "우리 할머니다" 공감, 외국인은 "이게 한국 할머니구나" 발견)

### 🍚 밥상 — "세시음식 운세" + "인생 한 마디 교환"
- **세시음식 운세:** 오늘 만든 음식이 주는 복 뽑기 — 떡국=장수, 송편=좋은 인연, 팥죽=액운 퇴치. **세시 스토리(26번) + 포춘쿠키 재미.**
- **인생 한 마디 교환:** 할머니가 인생 지혜 한마디, 손님이 소원 한마디. 밥상머리 크로스컬처 리추얼.

### 🎁 Take-home — "김치 지문 (Kimchi Fingerprint)"
- 손맛은 사람마다 달라 **내가 담근 김치는 세상에 하나뿐.** 이름표 붙인 **'당신의 손맛 김치'**를 가져가기.
- 발효되며 계속 변하는 **살아있는 기념품** — "집에 가서도 익어가는 나만의 한국".

## 추천 조합 (시그니처 3+1)
1. **플래그십: 한국 할머니 입양·계승·지속** (전체를 관통하는 서사)
2. **할머니 잔소리 빙고** (쿠킹 중 폭소·바이럴)
3. **단골 흥정 배틀·정 미션** (시장에서 '정·덤' 체험)
4. **김치 지문** (take-home 기념)
→ 이 넷이면 **감동(플래그십) + 폭소(빙고) + 로컬 진짜배기(흥정) + 손에 쥐는 기억(김치)** 이 다 잡힘.
